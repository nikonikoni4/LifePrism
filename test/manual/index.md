# 手动测试索引

## 手动测试列表

|---------|---------|---------|------|---------|

## 测试类型说明

- **UI 交互**：需要在浏览器中手动操作
- **视觉效果**：需要人工判断视觉呈现
- **用户体验**：需要评估交互流畅度
- **浏览器兼容性**：需要在多个浏览器中测试

## 测试状态说明

- **待执行**：测试文档已创建，未执行
- **通过**：最近一次测试通过
- **失败**：最近一次测试发现问题
- **已废弃**：测试不再需要

## 执行手动测试

1. 阅读测试文档：`test/manual/{test-name}.md`
2. 按照步骤执行测试
3. 记录测试结果
4. 如有问题，截图保存到 `test/manual/screenshots/`
5. 更新本索引文件的"最后执行"时间

## 添加新的手动测试

1. 在 `test/manual/` 下创建测试文档
2. 按照模板填写测试步骤
3. 更新本索引文件
4. 在 `test/scenarios/` 中关联对应的测试场景
