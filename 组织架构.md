# 前端组织架构

> 此文档记录 LifePrism 前端项目的文件组织结构


## 📋 页面模块标准结构

每个页面模块遵循以下标准结构：

```
page/{page-name}/
├── {PageName}.tsx        # 页面主组件
├── api.ts                # 页面专属 API 调用
├── types.ts              # 页面专属类型定义
├── index.ts              # 导出入口
└── components/           # 页面专属子组件
    ├── Component1.tsx
    └── Component2.tsx
```

## 🔗 导入路径规范

| 场景 | 导入来源 |
|------|----------|
| 页面内部组件 | `./components/ComponentName` |
| 页面内部类型 | `./types` |
| 页面内部 API | `./api` |
| 跨页面共享组件 | `../common` |
| 全局共享类型 | `../../shared/types` |
| 全局服务 | `../../services/serviceName` |
| Chatbot 模块 | `../chatbot` 或 `../../page/chatbot` |

---

## 🤖 AI 功能架构

| 模块 | 位置 | 职责 |
|------|------|------|
| Chatbot | `page/chatbot/` | 聊天机器人功能（会话管理、消息发送、聊天UI） |
| AI Service | `services/aiService.ts` | 通用 AI 工具（摘要生成、内容总结等非对话类功能） |

**使用场景：**
- 需要对话式交互 → 使用 `page/chatbot/` 的 `ChatPanel` 组件
- 需要调用 AI 生成内容（如摘要） → 使用 `services/aiService.ts`
