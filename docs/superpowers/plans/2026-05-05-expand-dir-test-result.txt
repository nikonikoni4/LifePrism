测试结果: ✅ 全部通过

- ✅ 获取空列表: {"expand_dirs":[]}
- ✅ 获取包含数据的列表: 正常返回

### 2. POST /api/v2/add_on/expand_dir
- ✅ 创建成功: 返回 201，包含 id 和 created_at
- ✅ 无效路径: 返回 400，错误信息 "路径不存在或无法访问"

- ✅ 更新成功: 返回更新后的数据
- ✅ ID 不存在: 返回 404，错误信息 "扩展文件夹不存在"

### 4. DELETE /api/v2/add_on/expand_dir/{id}
- ✅ 删除成功: 返回 204 状态码
- ✅ 删除后验证: 列表为空
