# PlanDoc 三数据源同步 — 全场景手动测试

## 场景总览

| # | Editor | MD | DB | 场景 | 状态 |
|---|--------|----|----|------|------|
| 1 | - | - | - | 无变更 | ✅ |
| 2 | ✓ | - | - | 仅编辑器修改 | ⚠️ |
| 3 | - | ✓ | - | 仅外部修改 MD | ⚠️ |
| 4 | - | - | ✓ | 仅任务池操作 | ✅ |
| 5 | ✓ | ✓ | - | 编辑器 + 外部 MD 冲突 | ❌ |
| 6 | ✓ | - | ✓ | 编辑器 + 任务池操作 | ✅ |
| 7 | - | ✓ | ✓ | 外部 MD + 任务池操作 | ❌ |

## 前置准备

### 环境要求
- 前后端均已启动（`npm run dev` + `python main.py`）
- 准备 VS Code 用于外部修改 MD 文件
- 打开浏览器 DevTools Console，便于观察错误

### 创建测试计划书

1. 在前端创建计划书，命名为 **"同步测试"**
2. 在编辑器中写入以下内容并 **保存**：

```markdown
# 同步测试计划书

<!-- lp:todoblock -->
- [ ] 任务A：保持不变
- [ ] 任务B：用于编辑器修改
- [ ] 任务C：用于外部修改
- [ ] 任务D：用于任务池操作
<!-- /lp:todoblock -->
```

3. 点击 **"同步"** 按钮，将任务同步到数据库
4. 确认任务池中出现 4 个任务（A/B/C/D），每个任务行末尾都有锚点
5. 用 VS Code 打开 MD 文件，确认路径：`{lifeprismData}/plan/{plan_doc_id}.md`

> **重要**：每个测试场景开始前，将计划书恢复到上述初始状态（4 个未完成任务、编辑器/MD/DB 三者一致）。

## 场景 1：无变更（基线验证）

**目的**：确认三者一致时，各操作不会引入意外变更。

### 测试 1.1：打开编辑器不触发变更

**步骤**：
1. 关闭计划书编辑器
2. 重新打开该计划书

**预期**：编辑器内容与 MD 文件完全一致，无任何差异。

**验证**：对比编辑器内容与 VS Code 中 MD 文件内容。

### 测试 1.2：同步无差异

**步骤**：
1. 确认编辑器已保存、MD 与 DB 一致
2. 点击"同步"按钮

**预期**：同步预检显示无差异（无新增、无删除、无更新），或直接提示"已是最新"。

**验证**：观察同步对话框/提示信息。

## 场景 2：仅编辑器修改 ⚠️

**目的**：验证 Editor → MD → DB 的单向流程。

### 测试 2.1：编辑器保存到 MD

**步骤**：
1. 在编辑器中将 `任务B：用于编辑器修改` 改为 `任务B-已修改`
2. 保存编辑器（Ctrl+S 或切换文档触发自动保存）

**预期**：
- MD 文件中 `任务B` 变为 `任务B-已修改`
- 数据库中 `任务B` **仍为原内容**（MD→DB 不自动同步）

**验证**：
1. VS Code 打开 MD 文件，确认 `任务B-已修改`
2. 查看任务池中 `任务B` 的显示内容（应仍为旧内容）

### 测试 2.2：编辑器保存 + 手动同步到 DB

**步骤**：
1. 接上一步，点击"同步"按钮

**预期**：
- 同步预检显示 `任务B` 内容有变更
- 确认后数据库更新，任务池显示 `任务B-已修改`

**验证**：任务池中 `任务B` 显示为 `任务B-已修改`。

### 测试 2.3：编辑器新增任务 + 同步

**步骤**：
1. 在编辑器的 todoblock 内新增一行 `- [ ] 任务E-编辑器新增`
2. 保存编辑器
3. 点击"同步"

**预期**：
- 同步预检显示新增 1 个任务
- 确认后 `任务E-编辑器新增` 出现在任务池中，自动生成锚点

**验证**：
1. 任务池中出现 `任务E-编辑器新增`
2. MD 文件中该行末尾有锚点 `<!-- lp:t-xxxxxxxx -->`

### 测试 2.4：编辑器删除任务 + 同步

**步骤**：
1. 在编辑器中删除 `任务C` 所在行
2. 保存编辑器
3. 点击"同步"

**预期**：
- 同步预检显示待删除 1 个任务（`任务C`）
- 需要 `confirm_delete=True` 才会执行删除
- 确认后任务池中 `任务C` 消失

**验证**：任务池中不再有 `任务C`。

### 测试 2.5：编辑器勾选完成 + 同步

**步骤**：
1. 在编辑器中将 `任务A` 的 `[ ]` 改为 `[x]`
2. 保存编辑器
3. 点击"同步"

**预期**：
- 同步后数据库中 `任务A` 状态变为 `completed`
- 任务池中 `任务A` 显示为已完成

**验证**：任务池中 `任务A` 的勾选状态。

### 测试 2.6：编辑器勾选取消+ 同步 （未通过）

**步骤**：

1. 在编辑器中将 `任务A` 的 `[x]` 改为 `[ ]`

**预期**：

- 任务池中 `任务A` 显示为未完成

3. **快速连续** 在任务池中：勾选 `任务A` 完成，立刻勾选 `任务D` 完成

**预期**：
- 两次操作各自触发 Save Hook，可能产生竞态条件
- 最终状态不确定，取决于时序

**验证**：
1. 等待操作完成，检查 MD 文件最终状态
2. 检查 `任务A` 和 `任务D` 是否都为 completed
3. 检查浏览器 Console 是否有错误
