# 同步全量触发机制 + LWW 时间相等跳过

## 版本

| 版本 | 更新内容 |
| ---- | -------- |
| 1.0 | 创建文档初稿 |

## 问题界定

### 问题简述

当前同步架构完全依赖客户端 `last_sync_time` 来判断增量范围（`SELECT * FROM {table} WHERE updated_at > ?`）。在两种现实场景下该机制失效：

1. **换服务器**：新服务器的数据库为空或只有部分数据，但客户端 `last_sync_time` 仍记录着对老服务器的同步进度，导致增量查询无法覆盖需要补齐的历史数据。
2. **云端数据损坏/重置**：云端数据库被删除重建后，客户端 `last_sync_time` 未清空，导致云端无法接收客户端的存量数据（Push 端 `query_incremental` 查询不到变更），也无法正确 Pull 云端的初始数据
