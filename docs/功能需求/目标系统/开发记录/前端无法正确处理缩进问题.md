## 未修复部分：段落前导空格丢失

### 现象

用户在编辑器中输入带前导空格的文本（如 `   前面有很多空格`），刷新后空格消失，保存后 MD 文件中的空格也被删除。

### 根因分析

空格在多个环节被丢失，核心瓶颈在 ProseMirror 层：

| 环节 | 问题 | 修复难度 |
|------|------|---------|
| ProseMirror DOM 解析 | 富文本编辑器将 HTML 解析为文档模型时，按 DOM 规范折叠前导空格 | 极难 |
| HTML 规范 | `<p>   文本</p>` 中前导空格被浏览器折叠 | 需 CSS 配合 |
| jsonToMarkdown() 的 .trim() | 列表项第 74/88/116 行主动 trim | 容易 |
| CSS 缺少 white-space | `.ProseMirror p` 没有 `pre-wrap` | 容易 |

### 数据流追踪

```
MD 文件 "   前面有很多空格"
  → markdownToHtml() → <p>   前面有很多空格</p>
  → Tiptap setContent(html) → ProseMirror DOM 解析 → 前导空格被折叠
  → editor.getJSON() → text 节点已无前导空格
  → jsonToMarkdown() → 输出时空格已丢失
```

### 难度评估：高

- 问题根因在 ProseMirror/Tiptap 的 DOM 解析层
- 可能的修复方向：用 `&nbsp;` 替换空格、自定义 ProseMirror 节点/插件、添加 `white-space: pre-wrap` CSS
- 每种方案都可能引发副作用（影响列表缩进、代码块、表格等）
