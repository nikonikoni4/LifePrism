## 界面元素说明

### 1. 状态主体栏 (Header)

- **左侧标题**：🎯 图标 + "每日聚焦"
- **中部统计**：
  - 完成进度：`3/8 完成`（半透明圆角胶囊）
  - 逾期警告：`⚠️ 1 项逾期`（红色底纹）

### 2. 操作工具栏 (Toolbar)

- **重置按钮**：蓝色图标，刷新/回归初始状态
- **展开子任务/全部折叠**：控制任务列表显示层级

### 3. 任务输入框

- **上方**：目标和计划书下拉选择器
- **下方**：`+ | Type to create a task...`

### 4. 任务卡片

使用 `TodoItemTreeDetailed.tsx` 组件实现。

**完整组成元素**：

1. **顶部标题栏 (Header)**
   - **左侧**：包含一个六点式的**拖拽手柄**和任务状态的**圆形复选框**
   - **中间**：任务标题文字（如"验证码逻辑"）
   - **右侧**：包含四个操作图标：**收起/展开箭头**、**调色盘（主题/分类）**、**+添加子项按钮** 和**垃圾桶（删除）**

2. **状态与标签区 (Info & Tags)**
   - 位于标题下方，展示任务的时间轴信息：
     - **开始时间**：带有日历图标
     - **预期时间**：带有秒表图标
   - **胶囊标签**（注意顺序）：
     1. **Goal 标签**（紫色 `bg-purple-50 text-purple-600`）：表示该任务所属的 Goal
     2. **Plan 标签**（蓝色 `bg-blue-50 text-blue-600`）：表示任务所属的计划书
     3. **delayStatus 标签**（橙色）：任务完成时间情况的标签，如"今日截止"

3. **内容/备注区 (Main Content)**（展开后显示）
   - 中间是一个明显的**输入框区域**
   - 上方带有标题"拖延/未完成原因"，并附带信息图标
   - 输入框中有占位符文字，提示用户记录原因以便复盘

4. **底部辅助信息 (Footer)**（展开后显示）
   - 卡片最底端以简洁的图标和文字确认**开始日期**和**预期结束时间**（或日期）
   - 点击日期可以选择开始和预期结束时间

## 交互规则

1. **选择日期**：点击日期选择器，弹出日期选择框 → 点击日期，显示所选择日期的当天的 todo
2. **添加顶级 todo**：顶级 todo 是指最高级别的 todo，在 todo 界面的输入框添加的都是最高级别的 todo
3. **添加特定目标和计划书的 todo**：可以通过上面的下拉选项卡选择当前已有的目标和计划书，选择之后添加的内容会自动绑定对应的目标和计划书
4. **添加新 todoitem**：在每个 todo 点击 + 可以增加新的 todoitem，新添加的 todoitem 的目标和计划书应该和父项一致
5. **同级拖拽**：任务可在同级别内拖拽排序
6. **双栏页面交互规则**：
   - 左侧 → 右侧：左侧日历点击一个日期，右侧可以快速切换到当前日期的详情界面
   - 右侧 → 左侧：暂时不增加交互

    id: number;

## 后端逻辑

### API 接口

| 方法 | 路径 | 描述 |
|:---|:---|:---|
| GET | `/api/v2/todos?date={date}` | 获取指定日期的任务 |
| POST | `/api/v2/todos` | 创建任务 |
| PUT | `/api/v2/todos/{id}` | 更新任务 |
| DELETE | `/api/v2/todos/{id}` | 删除任务 |

### 创建任务


对于在输入框输入顶级todo而言，输入内容后创建会直接发送内容给后端而不是本地创建；对于卡片，点击卡片上的+号按钮创建，然后弹出一个卡片输入框，可以输入内容，选择颜色，以及开始和结束时间。当卡片title为空时不能创建。颜色为随机颜
色，开始时间默认是当天，结束时间默认是null。将信息发送给后端
