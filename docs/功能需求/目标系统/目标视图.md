# 目标视图（组合1：目标 + 计划书）

> 双栏模式下：左侧【目标列表】+ 右侧【计划书列表】

## 界面设计

### 左侧：目标列表

```
┌────────────────────────────────────┐
│  🎯 目标                    [+ 新增] │
├────────────────────────────────────┤
│  ┌──────────────────────────────┐  │
│  │ ○ 学习 React               → │  │
│  │   3 个计划书 · 进行中         │  │
│  └──────────────────────────────┘  │
│  ┌──────────────────────────────┐  │
│  │ ○ 健身计划                  → │  │
│  │   1 个计划书 · 进行中         │  │
│  └──────────────────────────────┘  │
└────────────────────────────────────┘
```

### 右侧：计划书列表

点击左侧目标后，右侧显示该目标关联的计划书列表。

```
┌────────────────────────────────────┐
│  📋 学习 React 的计划书     [+ 新增] │
├────────────────────────────────────┤
│  ┌──────────────────────────────┐  │
│  │ 第一阶段：基础学习            │  │
│  │ 状态: 进行中 · 5 个任务       │  │
│  └──────────────────────────────┘  │
│  ┌──────────────────────────────┐  │
│  │ 第二阶段：项目实战            │  │
│  │ 状态: 草稿                   │  │
│  └──────────────────────────────┘  │
└────────────────────────────────────┘
```

---

## 交互规则

1. **选择目标**：点击左侧目标卡片 → 右侧显示关联计划书
2. **新增目标**：点击左侧 [+ 新增] → 弹出目标创建表单
3. **新增计划书**：点击右侧 [+ 新增] → 弹出计划书创建表单，自动关联当前目标
4. **编辑目标**：双击目标卡片 → 进入编辑模式
5. **删除目标**：hover 显示删除按钮 → 确认后级联删除关联计划书和任务

## 后端逻辑

### API 接口

| 方法 | 路径 | 描述 |
|:---|:---|:---|
| GET | `/api/v2/goals` | 获取目标列表 |
| POST | `/api/v2/goals` | 创建目标 |
| PUT | `/api/v2/goals/{id}` | 更新目标 |
| DELETE | `/api/v2/goals/{id}` | 删除目标（级联删除） |
| GET | `/api/v2/goals/{id}/plan_docs` | 获取目标关联的计划书 |

### 业务逻辑

**创建目标**：
- 生成唯一 ID
- 默认状态为 `active`
- 记录创建时间

**删除目标**：
- 查找关联的 PlanDoc
- 查找关联的 TodoItem
- 按顺序删除：TodoItem → PlanDoc → Goal
