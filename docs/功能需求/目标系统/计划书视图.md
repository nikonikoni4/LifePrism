# 计划书视图（组合2：计划书 + 任务池）

> 双栏模式下：左侧【计划书编辑器】+ 右侧【任务池】

## 界面设计

### 左侧：计划书编辑器

Markdown 编辑器，支持任务锚点语法。

```
┌────────────────────────────────────┐
│  📝 第一阶段：基础学习        [保存] │
├────────────────────────────────────┤
│                                    │
│  ## 学习目标                        │
│                                    │
│  掌握 React 基础概念               │
│                                    │
│  ## 任务清单                        │
│                                    │
│  - [ ] 学习 JSX 语法 <!--task:1--> │
│  - [ ] 理解组件生命周期             │
│  - [ ] 完成官方教程                 │
│                                    │
│  [同步任务到任务池]                  │
│                                    │
└────────────────────────────────────┘
```

### 右侧：任务池预览

显示从计划书解析出的任务。

```
┌────────────────────────────────────┐
│  📦 任务池                          │
├────────────────────────────────────┤
│  来源: 第一阶段：基础学习            │
│  ┌──────────────────────────────┐  │
│  │ □ 学习 JSX 语法              │  │
│  └──────────────────────────────┘  │
│  ┌──────────────────────────────┐  │
│  │ □ 理解组件生命周期            │  │
│  └──────────────────────────────┘  │
│  ┌──────────────────────────────┐  │
│  │ □ 完成官方教程               │  │
│  └──────────────────────────────┘  │
└────────────────────────────────────┘
```

---

## 交互规则

1. **编辑计划书**：直接在 Markdown 编辑器中编辑
2. **同步任务**：点击 [同步任务到任务池] → 解析 Markdown 中的任务项 → 创建/更新 TodoItem
3. **任务锚点**：使用 `<!--task:id-->` 语法标记已同步的任务，支持双向同步

---

## 后端逻辑

### API 接口

| 方法 | 路径 | 描述 |
|:---|:---|:---|
| GET | `/api/v2/plan_docs` | 获取计划书列表 |
| POST | `/api/v2/plan_docs` | 创建计划书 |
| PUT | `/api/v2/plan_docs/{id}` | 更新计划书 |
| DELETE | `/api/v2/plan_docs/{id}` | 删除计划书（级联删除任务） |
| POST | `/api/v2/plan_docs/{id}/sync` | 同步任务到任务池 |

### 同步逻辑

**MD → 数据库**：
1. 解析 Markdown 中的 `- [ ]` 或 `- [x]` 格式
2. 检查是否有 `<!--task:id-->` 锚点
3. 有锚点：更新对应 TodoItem
4. 无锚点：创建新 TodoItem，回写锚点到 MD

**数据库 → MD**：
1. 查找 MD 中的任务锚点
2. 根据 TodoItem 状态更新 `[ ]` 或 `[x]`
