## 一、计划书删除任务同步到任务池

### 问题描述

当前在计划书（MD 文件）中删除任务行后，数据库中的对应任务不会被删除。下次同步时，由于锚点仍存在于数据库，不会重新创建，但任务也不会被清理。

**影响**：
- 数据库中存在"幽灵任务"（MD 中已删除但数据库中仍存在）
- 用户在任务池视图中仍能看到已删除的任务

### 解决方案

#### 交互流程

```
用户点击"同步"按钮
    ↓
POST /api/v2/taskpool/sync { plan_doc_id, dry_run: true }  ← 预检模式
    ↓
后端对比 MD 和数据库，返回差异：
{
    to_create: [...],
    to_update: [...],
    to_delete: [{ id, content, anchor_id }, ...]  ← 将被删除的任务
}
    ↓
前端判断 to_delete.length > 0 ?
    ├── 是 → 弹出确认对话框
    │       "检测到以下任务在计划书中已删除：
    │        - 任务A
    │        - 任务B
    │        是否同步删除？"
    │       ├── 确认 → POST /api/v2/taskpool/sync { plan_doc_id, confirm_delete: true }
    │       └── 取消 → POST /api/v2/taskpool/sync { plan_doc_id, confirm_delete: false }
    └── 否 → 直接执行同步
```

```python
def sync_plan_doc(plan_doc_id: str, dry_run: bool = False, confirm_delete: bool = False):
    # ... 现有解析逻辑 ...

    # 获取 MD 中的锚点集合
    md_anchors = {task['anchor_id'] for task in parsed_tasks if task['anchor_id']}

    # 获取数据库中的任务
    db_tasks = todo_provider.get_todos_by_plan_doc_id(plan_doc_id)
    db_anchor_map = {task['anchor_id']: task for task in db_tasks if task.get('anchor_id')}

    # 找出需要删除的任务
    to_delete_anchors = set(db_anchor_map.keys()) - md_anchors
    to_delete_tasks = [db_anchor_map[anchor] for anchor in to_delete_anchors]

    # 预检模式：只返回差异
    if dry_run:
        return {
            'to_create': [...],
            'to_update': [...],
            'to_delete': [{'id': t['id'], 'content': t['content'], 'anchor_id': t['anchor_id']}
                          for t in to_delete_tasks],
        }

    # 执行删除（仅当 confirm_delete=True）
    deleted_count = 0
    if confirm_delete and to_delete_tasks:
        for task in to_delete_tasks:
            todo_provider.delete_todo(task['id'])
            deleted_count += 1

    # ... 现有创建/更新逻辑 ...

    return {
        'created': created_count,
        'updated': updated_count,
        'deleted': deleted_count,
        'total': len(parsed_tasks),
    }
```

## 二、DailyView 增删改查同步到 MD

### 问题描述

当前在 DailyView 中对有 `plan_doc_id` 的任务进行增删改操作时，只更新数据库，不会同步更新 MD 文件。导致 MD 文件与数据库状态不一致。

**影响**：
- 在 DailyView 添加的子任务不会出现在计划书中
- 在 DailyView 修改的任务内容不会同步到计划书
- 在 DailyView 删除的任务仍存在于计划书中

### 解决方案

#### 数据流

```
前端操作（DailyView）
    ↓
后端数据库更新
    ↓
MD 文档更新（如果 todo.plan_doc_id 存在）
    ↓
前端状态更新（通过 TaskPoolProvider 同步到所有视图）
```

#### 继承规则

当在有 `plan_doc_id` 的 todo 项下添加子项时，子项需要继承：
- `plan_doc_id`
- `goal_id`（如有）
- 自动生成 `anchor_id`（格式：`t-{uuid[:8]}`）

#### MD 更新操作对照表

| 操作 | 触发条件 | MD 更新逻辑 | 难度 |
|------|----------|-------------|------|
| 新增子任务 | `parent.plan_doc_id` 存在 | 在父任务下方插入，缩进 +2 | 中 |
| 新增根任务 | 指定了 `plan_doc_id` | 在 todoblock 末尾追加 | 低 |
| 修改内容 | `todo.anchor_id` 存在 | 定位锚点行，替换内容部分 | 低 |
| 删除任务 | `todo.anchor_id` 存在 | 定位锚点行，删除该行及子任务 | 中 |
| 完成任务 | `todo.anchor_id` 存在 | 定位锚点行，`[ ]` → `[x]` | 低（已实现） |

#### 核心难点：子任务插入位置

```markdown
<!-- lp:todoblock -->
- [ ] 父任务A <!-- lp:t-aaa -->
  - [ ] 子任务A1 <!-- lp:t-a1 -->
  - [ ] 子任务A2 <!-- lp:t-a2 -->    ← 新子任务应插入这里之后
- [ ] 父任务B <!-- lp:t-bbb -->
<!-- /lp:todoblock -->
```

**需要解决的问题**：
1. 通过父任务锚点找到父任务行号
2. 找到父任务的最后一个子任务（可能有多层嵌套）
3. 计算正确的缩进级别
4. 在正确位置插入新行

#### 后端改动

**1. 新增 MD 操作函数** (`taskpool_service.py`)

```python
def _insert_todo_to_md(plan_doc_id: str, new_todo: dict, parent_anchor_id: str | None):
    """在 MD 文件中插入新任务"""
    content = _read_plan_doc_content(plan_doc_id)
    lines = content.split('\n')

    # 1. 解析 todoblock 结构
    todoblock_start, todoblock_end = _find_todoblock_range(lines)
    parsed = _parse_todoblock_with_line_numbers(lines[todoblock_start:todoblock_end])
    # parsed = [{ line_no, indent, content, anchor_id, children: [...] }, ...]

    if parent_anchor_id:
        # 2. 找到父任务及其最后一个后代的行号
        parent_node = _find_node_by_anchor(parsed, parent_anchor_id)
        if not parent_node:
            # 父任务不存在，作为根级任务插入
            insert_line = todoblock_end - 1
            indent = 0
        else:
            insert_line = _get_last_descendant_line(parent_node)
            indent = parent_node['indent'] + 2  # 子任务缩进 +2 空格
    else:
        # 根级任务：插入到 todoblock 末尾
        insert_line = todoblock_end - 1
        indent = 0

    # 3. 构建新行
    new_line = ' ' * indent + f"- [ ] {new_todo['content']} <!-- lp:{new_todo['anchor_id']} -->"

    # 4. 插入
    lines.insert(todoblock_start + insert_line + 1, new_line)

    # 5. 写回
    _write_plan_doc_content(plan_doc_id, '\n'.join(lines))


def _update_todo_in_md(plan_doc_id: str, anchor_id: str, new_content: str):
    """更新 MD 文件中的任务内容"""
    content = _read_plan_doc_content(plan_doc_id)
    lines = content.split('\n')

    # 通过锚点找到行
    anchor_pattern = f"<!-- lp:{anchor_id} -->"
    for i, line in enumerate(lines):
        if anchor_pattern in line:
            # 替换内容部分，保留缩进、checkbox 和锚点
            match = re.match(r'^(\s*- \[[ x]\] ).*( <!-- lp:.*? -->)$', line)
            if match:
                lines[i] = f"{match.group(1)}{new_content}{match.group(2)}"
                break

    _write_plan_doc_content(plan_doc_id, '\n'.join(lines))


def _delete_todo_from_md(plan_doc_id: str, anchor_id: str):
    """从 MD 文件中删除任务（包括子任务）"""
    content = _read_plan_doc_content(plan_doc_id)
    lines = content.split('\n')

    # 找到任务行及其缩进
    anchor_pattern = f"<!-- lp:{anchor_id} -->"
    target_line = None
    target_indent = 0

    for i, line in enumerate(lines):
        if anchor_pattern in line:
            target_line = i
            target_indent = len(line) - len(line.lstrip())
            break

    if target_line is None:
        return

    # 找出需要删除的行范围（包括所有子任务）
    lines_to_delete = [target_line]
    for i in range(target_line + 1, len(lines)):
        line = lines[i]
        if not line.strip():
            continue
        current_indent = len(line) - len(line.lstrip())
        if current_indent > target_indent and '- [' in line:
            lines_to_delete.append(i)
        else:
            break

    # 从后往前删除，避免索引偏移
    for line_no in reversed(lines_to_delete):
        del lines[line_no]

    _write_plan_doc_content(plan_doc_id, '\n'.join(lines))
```

**2. 辅助函数** (`taskpool_service.py`)

```python
def _find_todoblock_range(lines: list[str]) -> tuple[int, int]:
    """找到 todoblock 的起止行号"""
    start = end = -1
    for i, line in enumerate(lines):
        if '<!-- lp:todoblock -->' in line:
            start = i
        elif '<!-- /lp:todoblock -->' in line:
            end = i
            break
    return start, end


def _find_node_by_anchor(nodes: list[dict], anchor_id: str) -> dict | None:
    """递归查找指定锚点的节点"""
    for node in nodes:
        if node.get('anchor_id') == anchor_id:
            return node
        if node.get('children'):
            found = _find_node_by_anchor(node['children'], anchor_id)
            if found:
                return found
    return None


def _get_last_descendant_line(node: dict) -> int:
    """获取节点最后一个后代的行号"""
    if not node.get('children'):
        return node['line_no']
    return _get_last_descendant_line(node['children'][-1])
```

#### 边界情况处理

| 情况 | 处理方式 |
|------|----------|
| todoblock 不存在 | 创建 todoblock 后再插入 |
| 父任务锚点找不到 | 作为根级任务插入到末尾 |
| 多层嵌套子任务 | 递归查找最后后代 |
| 缩进不规范（tab vs 空格） | 统一转换为 2 空格缩进 |
| 任务没有锚点 | 跳过 MD 更新（非 MD 来源的任务） |
| MD 文件不存在 | 跳过 MD 更新，记录警告日志 |
