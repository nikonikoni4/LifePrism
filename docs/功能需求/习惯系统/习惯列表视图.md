# 习惯列表视图

## 交互规则

1. **打卡**：点击习惯卡片的 [✓] 按钮 → 记录当日完成
2. **查看历史**：点击 [查看历史] → 弹出历史记录弹窗
3. **暂停习惯**：点击 [暂停] → 习惯变为灰色，不计入统计
4. **筛选热力图**：下拉选择单个习惯 → 热力图只显示该习惯数据
5. **新增习惯**：点击 [+ 新增] → 弹出创建表单

---

## 状态展示

| 状态 | 视觉表现 | 说明 |
|------|----------|------|
| active | 正常显示 | 活跃中的习惯 |
| paused | 灰色/半透明 | 暂停中，不计入统计 |
| archived | 隐藏或折叠区 | 已归档，可查看历史 |

## 后端逻辑

### API 接口

| 方法 | 路径 | 描述 |
|:---|:---|:---|
| GET | `/api/v2/habits` | 获取习惯列表 |
| POST | `/api/v2/habits` | 创建习惯 |
| PUT | `/api/v2/habits/{id}` | 更新习惯 |
| DELETE | `/api/v2/habits/{id}` | 删除习惯 |
| POST | `/api/v2/habits/{id}/checkin` | 打卡 |
| GET | `/api/v2/habits/{id}/history` | 获取历史记录 |
| GET | `/api/v2/habits/heatmap` | 获取热力图数据 |

### 打卡逻辑

```json
POST /api/v2/habits/{id}/checkin
{
  "date": "2026-01-15",
  "completed": true,
  "note": "今天状态不错"
}
```

**处理流程**：
1. 创建 HabitCheckIn 记录
2. 更新当前挑战的 completedCount
3. 检查挑战是否完成
4. 如完成，判断成功/失败，更新等级

### 挑战完成判定

```python
def check_challenge_completion(challenge):
    if today > challenge.end_date:
        if challenge.completed_count >= challenge.required_completions:
            # 成功，升级
            challenge.status = 'succeeded'
            habit.current_level = challenge.to_level
        else:
            # 失败，降级
            challenge.status = 'failed'
            habit.current_level = max(0, challenge.from_level - 1)

        # 创建新挑战
        create_next_challenge(habit)
```
