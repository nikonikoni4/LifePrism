# 习惯系统数据设计草稿

## 一、数据模型

### 1. Habit（习惯）

```typescript
interface Habit {
  id: string;                    // 唯一标识
  name: string;                  // 习惯名称
  description?: string;          // 习惯描述（可选）
  frequency: HabitFrequency;     // 频率配置 

  // 锚点相关
  anchorType?: 'time' | 'event' | 'scene';  // 锚点类型
  anchorDescription?: string;    // 锚点描述，如"起床后"、"午饭后"
  anchorHabitId?: string;        // 关联的锚点习惯ID（可选）

  // 等级系统
  currentLevel: number;          // 当前等级 0-4
  currentChallenge: HabitChallenge;  // 当前进行中的挑战

  // 状态
  status: 'active' | 'paused' | 'archived';

  // 关联
  goalId?: string;               // 关联的目标ID（可选，与goalsV2联动）
  valueId?: string;              // 关联的价值ID（可选，来自Mind Space）
  commitmentId?: string;         // 关联的承诺ID（可选，来自Mind Space）

  // 时间戳
  createdAt: string;             // 创建时间
  updatedAt: string;             // 更新时间
  pausedAt?: string;             // 暂停时间
}
```

### 2. HabitFrequency（频率配置）

```typescript
interface HabitFrequency {
  type: 'daily' | 'weekdays' | 'weekly' | 'custom';

  // weekly 类型时使用
  timesPerWeek?: number;         // 每周N次

  // custom 类型时使用
  specificDays?: number[];       // 指定星期几 [1,2,3,4,5,6,7]，1=周一
}



// 示例
const dailyFreq: HabitFrequency = { type: 'daily' };
const weekdaysFreq: HabitFrequency = { type: 'weekdays' };
const weeklyFreq: HabitFrequency = { type: 'weekly', timesPerWeek: 3 };
const customFreq: HabitFrequency = { type: 'custom', specificDays: [1, 3, 5] };
```

### 3. HabitChallenge（挑战）

```typescript
interface HabitChallenge {
  id: string;
  habitId: string;

  // 挑战目标
  targetDays: number;            // 目标天数，如 21
  requiredCompletions: number;   // 需要完成的次数，如 18

  // 等级变化
  fromLevel: number;             // 起始等级
  toLevel: number;               // 目标等级

  // 进度
  startDate: string;             // 挑战开始日期
  endDate: string;               // 挑战结束日期（计算得出）
  completedCount: number;        // 已完成次数

  // 结果
  status: 'in_progress' | 'succeeded' | 'failed';
  finishedAt?: string;           // 完成时间
}
```
**重要**: 当设置了频率之后需要计算最长完成时间限制，比如每周4次，完成8次，那么最长时间就是14天

### 4. HabitCheckIn（打卡记录）

```typescript
interface HabitCheckIn {
  id: string;
  habitId: string;
  challengeId: string;           // 所属挑战ID

  date: string;                  // 打卡日期 YYYY-MM-DD
  completed: boolean;            // 是否完成

  // 可选扩展
  note?: string;                 // 打卡备注
  completedAt?: string;          // 完成时间戳
}
```

### 5. HabitHistory（历史记录）

```typescript
interface HabitHistory {
  id: string;
  habitId: string;

  // 挑战结果快照
  challenge: HabitChallenge;

  // 等级变化
  levelChange: 'up' | 'down' | 'reset';
  fromLevel: number;
  toLevel: number;

  // 统计
  actualCompletions: number;     // 实际完成次数

  createdAt: string;
}
```

### 6. Value（价值）

来自 Mind Space 模块，表示用户认为重要的生活价值观。

```typescript
interface Value {
  id: string;                    // 唯一标识
  name: string;                  // 价值名称，如"身心健康"、"持续学习"
  description?: string;          // 价值描述（可选）

  // 时间戳
  createdAt: string;
  updatedAt: string;
}
```

### 7. Commitment（承诺）

来自 Mind Space 模块，表示用户对自己做出的承诺。

```typescript
interface Commitment {
  id: string;                    // 唯一标识
  name: string;                  // 承诺名称，如"每天留出时间给自己"
  description?: string;          // 承诺描述（可选）
  valueId?: string;              // 关联的价值ID（可选，承诺可以源于某个价值）

  // 时间戳
  createdAt: string;
  updatedAt: string;
}
```

## 二、数据库表设计（SQLite）

### habits 表

```sql
CREATE TABLE habits (
    id TEXT PRIMARY KEY,
    name TEXT NOT NULL,
    description TEXT,

    -- 频率配置（JSON存储）
    frequency_type TEXT NOT NULL,  -- 'daily' | 'weekdays' | 'weekly' | 'custom'
    frequency_config TEXT,         -- JSON: { timesPerWeek?: number, specificDays?: number[] }

    -- 锚点
    anchor_type TEXT,              -- 'time' | 'event' | 'scene'
    anchor_description TEXT,
    anchor_habit_id TEXT,

    -- 等级
    current_level INTEGER DEFAULT 0,

    -- 状态
    status TEXT DEFAULT 'active',  -- 'active' | 'paused' | 'archived'

    -- 关联
    goal_id TEXT,
    value_id TEXT,                 -- 关联的价值ID
    commitment_id TEXT,            -- 关联的承诺ID

    -- 时间戳
    created_at TEXT NOT NULL,
    updated_at TEXT NOT NULL,
    paused_at TEXT,

    FOREIGN KEY (anchor_habit_id) REFERENCES habits(id),
    FOREIGN KEY (goal_id) REFERENCES goals(id),
    FOREIGN KEY (value_id) REFERENCES values(id),
    FOREIGN KEY (commitment_id) REFERENCES commitments(id)
);
```

### values 表（Mind Space）

```sql
CREATE TABLE values (
    id TEXT PRIMARY KEY,
    name TEXT NOT NULL,
    description TEXT,

    created_at TEXT NOT NULL,
    updated_at TEXT NOT NULL
);
```

### commitments 表（Mind Space）

```sql
CREATE TABLE commitments (
    id TEXT PRIMARY KEY,
    name TEXT NOT NULL,
    description TEXT,
    value_id TEXT,                 -- 关联的价值ID（可选）

    created_at TEXT NOT NULL,
    updated_at TEXT NOT NULL,

    FOREIGN KEY (value_id) REFERENCES values(id)
);
```

### habit_challenges 表

```sql
CREATE TABLE habit_challenges (
    id TEXT PRIMARY KEY,
    habit_id TEXT NOT NULL,

    -- 目标
    target_days INTEGER NOT NULL,
    required_completions INTEGER NOT NULL,

    -- 等级
    from_level INTEGER NOT NULL,
    to_level INTEGER NOT NULL,

    -- 进度
    start_date TEXT NOT NULL,
    end_date TEXT NOT NULL,
    completed_count INTEGER DEFAULT 0,

    -- 状态
    status TEXT DEFAULT 'in_progress',  -- 'in_progress' | 'succeeded' | 'failed'
    finished_at TEXT,

    created_at TEXT NOT NULL,

    FOREIGN KEY (habit_id) REFERENCES habits(id)
);
```

### habit_checkins 表

```sql
CREATE TABLE habit_checkins (
    id TEXT PRIMARY KEY,
    habit_id TEXT NOT NULL,
    challenge_id TEXT NOT NULL,

    date TEXT NOT NULL,           -- YYYY-MM-DD
    completed INTEGER NOT NULL,   -- 0 or 1

    note TEXT,
    completed_at TEXT,

    FOREIGN KEY (habit_id) REFERENCES habits(id),
    FOREIGN KEY (challenge_id) REFERENCES habit_challenges(id),

    UNIQUE(habit_id, date)        -- 每个习惯每天只能有一条记录
);
```

### habit_history 表

```sql
CREATE TABLE habit_history (
    id TEXT PRIMARY KEY,
    habit_id TEXT NOT NULL,
    challenge_id TEXT NOT NULL,

    level_change TEXT NOT NULL,   -- 'up' | 'down' | 'reset'
    from_level INTEGER NOT NULL,
    to_level INTEGER NOT NULL,
    actual_completions INTEGER NOT NULL,

    created_at TEXT NOT NULL,

    FOREIGN KEY (habit_id) REFERENCES habits(id),
    FOREIGN KEY (challenge_id) REFERENCES habit_challenges(id)
);
```

## 四、默认挑战配置

建议的等级挑战默认值：

| 等级变化 | 目标天数 | 需完成天数 | 完成率要求 |
|----------|----------|------------|------------|
| 0 → 1 | 14 | 12 | 85.7% |
| 1 → 2 | 21 | 18 | 85.7% |
| 2 → 3 | 30 | 25 | 83.3% |
| 3 → 4 | 60 | 50 | 83.3% |
| 4 维持 | 90 | 75 | 83.3% |

用户可自定义挑战目标。
