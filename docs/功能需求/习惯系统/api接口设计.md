## 基础增删改查 API 

| 含义     | 方法   | api url                    | 备注                                               |
| -------- | ------ | -------------------------- | -------------------------------------------------- |
| 获取习惯 | get    | /api/v2/habits/            | 由于习惯最多不过几十个，所以直接获取全部，不用分页 |
| 增加习惯 | post   | /api/v2/habits/            |                                                    |
| 修改习惯 | put    | /api/v2/habits/{habits_id} |                                                    |
| 删除习惯 | delete | /api/v2/habits/{habits_id} |                                                    |

## 统计数据查询

|              | 方法 | api url              | 查询参数                  | 备注                                                       |
| ------------ | ---- | -------------------- | ------------------------- | ---------------------------------------------------------- |
| 获取统计数据 | get  | /api/v2/habits/stats | date或start_date end_date | 查询每日的完成率，可以查询指定日期或时间段，用于绘制热力图 |

参数说明: date和start_date end_date只需要满足一个。若同时满足，优先时间段查询，并且发出警告。

| 参数       | 类型 |                        |
| ---------- | ---- | ---------------------- |
| date       | str  | 指定日期 YYYY-MM-DD    |
| start_date | str  | 指定开始日期YYYY-MM-DD |
| end_date   | str  | 指定结束日期YYYY-MM-DD |
