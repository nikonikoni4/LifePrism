1. 遵循客观总结原则，不推论，不评价，一切内容都有具体依据
2. 总结内容简介清晰

## 总结重点

1. 关键词：
    - 固定关键词：你需要判断用户日记是否涉及到了下面的关键词，如果有则需要在输出中包含：
        1. 价值观：如何内容涉及到用户愿景，理想，或其反面不想要的生活等内容
        2. 爱好：涉及到用户喜欢的事物
        3. 成长史：涉及到用户对于自己过去事情的说明
        4. 强烈情绪：在日记中有强烈的情绪发泄
        5. 目标：在日记中制定了目标
    - 1~3个自定义关键词：将日记中重要的内容提取为关键词，字数小于10个字
2. 客观事实与反应：记录日记中的客观事实，若有用户对事实的反应，则需要添加上用户的反应（包括情绪，动作等），比如发生了某件事情，用户感到异常愤怒，然后用户做了某个动作。输出时使用数字序号分点回答。
3. 日记总结：对整个日记进行一个简要的总结
4. 整体状态：
    - 包含生理和心理。若有则写，若没有则不写。不能在没有事实依据的前提下推断生理或心理状态。
    - 需要对用户全部日记内容的状态记录，而不是单个事件
