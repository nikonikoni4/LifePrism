**0. 先和大家打个招呼吧 👋**

* **你是谁：** 一名研二学生

* **你是怎么用 TRAE 把 Demo 做出来的：** 通过 TRAE 的智能体配置、文档管理和命令工具，实现高效的人机协同开发。**为什么这样做**：让 AI 能够理解项目上下文、遵循统一规则、产出符合需求的高质量成果，从而提高开发效率和代码质量。

### 1. 为不同模块设置独立智能体，实现上下文隔离

为不同模块设置专门的智能体，在提示词中为每个智能体设定专门的规则以及必须阅读的本地文档；为不同智能体配置不同的工具（内置工具和 MCP 工具）；实现不同智能体拥有独立的初始上下文环境。

**目的**：避免不同模块知识互相干扰，实现上下文隔离，让专门的任务使用专门的智能体，提升回答精准度和开发效率。

### 2. 打造为 AI 而生的项目上下文

在项目根目录添加 `AGENTS.md` 或 `CLAUDE.md` 作为总项目的导航地图，添加最基础的项目规则（不宜超过 200 行），包括文档体系总览、文档阅读规则和核心工程规则。

**目的**：让智能体快速理解项目结构和规则，减少人工解释成本，确保 AI 遵循统一的工程实践。

### 3. 构建结构化的 docs 文件夹

在 `docs/` 文件夹下放置以下目录：

- **`specs/`（产品规格文档）**：承载业务意图、业务规则、领域概念，以及规范性技术契约
- **`PRD/`（产品需求文档）**：描述产品的目标、用户需求和功能范围
- **`ADR/`（架构决策记录）**：记录对于长期具有重要作用的架构修改决定
- **`rules/`（规则文档）**：包含编码规范、文档编写规范等约束性规则
- **`history-bugs/`（历史 Bug 记录）**：存放可复用的 Bug 经验
- **`plans/`（执行计划）**：执行过程中的任务分解和执行记录

**目的**：为智能体提供结构化的知识体系，使其能够按需查找信息，同时保证项目知识的可追溯性和一致性。

### 4. 使用 `/spec` 命令设计规格文档

使用 TRAE 的 `/spec` 命令来设计当前需求的规格文档，明确功能的业务意图、核心规则和技术契约。

**目的**：建立需求与实现之间的明确契约，确保开发过程不偏离需求方向，为智能体提供清晰的实现边界。

### 5. 使用 `/plan` 命令设计执行计划

使用 `/plan` 命令来设计如何执行任务，将大任务分解为多个可执行的子步骤，每个步骤都有明确目标。

**目的**：将复杂任务拆解为可控的子任务，提高开发过程的可管理性和可追踪性，便于智能体按步骤完成工作。

### 6. 在 `.agents` 目录下配置自定义 Skill

在 `~/.agents` 或项目目录下的 `./.agents` 中添加全局或项目专属的 skill，覆盖界面开发、接口实现、文档编写等不同领域。

**目的**：让智能体掌握项目特定的技能和知识，实现项目专属能力的复用，减少重复训练和人工调整成本。

### 7. 设计专门的 Hook 来约束智能体行为

在项目设置中配置专门的 Hook，在 AI 准备修改代码前触发规则检查，在 AI 完成任务后检查文档更新，设置自动化脚本在特定条件下运行测试或代码格式化。

**目的**：实现自动化质量保障，在关键节点约束智能体行为，确保 AI 生成的成果符合项目规范，减少人工审查工作量。

**1. Demo 简介**

* 是什么：基于 Electron 的桌面应用，一站式数据驱动成长伴侣。通过记录外在行为与内在感受，将数据转化为清晰的自我认知与持续的行动指南。

* 面向谁：关注个人成长、自我管理、时间效率的人群，包括学生、职场人士、自由职业者、创业者等所有希望通过数据驱动实现自我提升的用户。

* 主要功能：

  **三大核心模块：**

  - **LifeWatch 时间追踪与行为分析**：作为个人时间管家，通过自动追踪和智能分类，帮助用户深入了解时间的流向。核心能力包括：智能时间追踪（自动记录应用和网站活动时间）、可视化时间轴（24小时时间块展示，精确到分钟级别）、AI 智能分类（自动将活动归类到工作、学习、娱乐等类别）、行为分析（深度分析行为模式，发现时间使用规律）。【待上传：时间轴视图截图】

  - **GoalMaster 目标管理系统**：采用目标-计划-任务池-日历的四层架构，帮助用户将宏大目标拆解为可执行的日常行动。核心能力包括：目标管理（设定长期目标，追踪里程碑进度）、计划文档（为目标制定详细执行计划，支持 Markdown）、任务池（将计划拆解为具体任务）、日历分配（将任务分配到具体日期）、时间投入统计（自动关联 LifeWatch 数据）。【待上传：目标管理界面截图】

  - **Mind Space 内心世界探索**：私密的心灵空间，通过日记、情绪记录和深度反思，帮助用户建立与内在自我的连接。核心能力包括：情绪追踪（识别情绪触发因素和模式）、日记书写（自由记录生活点滴与内心感悟）、价值观梳理（建立人生指南针）。【待上传：情绪界面截图】

  **拓展功能：**

  - **WAID（What Am I Doing）浮窗**：实时活动提醒浮窗，帮助用户保持专注。核心能力包括：实时显示当前活动、快速标记和分类当前任务、避免时间黑洞。【待上传：WAID浮窗截图】

  - **微信渠道 Agent 助手**：随时随地的 AI 成长助手，通过微信与 LifePrism 交互。核心能力包括：通过微信查询时间统计、目标进度、情绪记录等数据；接收行为分析报告和目标提醒推送；多轮对话保持上下文，提供持续的智能陪伴。【待上传：微信通道截图】

**2. Demo 创作思路**

* **灵感来源:**

  这个项目源于一个极其个人化的痛点——作为一名研二学生,每天坐在电脑前超过 10 小时,却常常在睡前反思时说不出时间究竟花在了哪里。尝试过 ActivityWatch等时间追踪工具,但它们只能告诉我"今天用了 3 小时浏览器",却无法回答我真正关心的问题:这 3 小时是在深度阅读论文,还是在无意义地刷网页?我在为哪个目标努力?当时的心情如何?

  真正的转折点发生在一次焦虑的深夜——我发现自己对时间、情绪和目标的失控感不是因为缺少数据,而是**数据之间缺乏连接**。时间管理 App、习惯打卡工具、日记软件各自为政,无法回答"心情低落的日子是否与某个习惯中断有关""目标进度缓慢是因为时间分配不合理还是计划本身有问题"这样的深层问题。

  同时,我在接触接纳承诺疗法(ACT)的心理学框架时,深受其"从觉察到行动"理念的启发——真正的改变不是从"我要更努力"开始,而是从"我清楚地看见自己"开始。LifePrism 的名字正是这个理念的体现:像三棱镜分解光谱一样,将生活的复杂性分解为可见、可理解、可行动的维度。

* **想解决的问题:**

  核心痛点可以归纳为四个层次:

  1. **时间感知模糊** — "感觉忙了一整天但不知道忙了什么",无法精确知道每天的时间分配,更无法理解行为背后的上下文(在做什么、为了什么目标、感受如何)。

  2. **记录成本过高** — 手动记录时间、心情、习惯需要极强的自律,大多数人坚持不过一周。现有工具要么完全手动(成本高),要么完全自动但只停留在表面数据(缺乏深度理解)。

  3. **数据孤岛问题** — 时间管理工具、习惯打卡 App、日记软件各自独立,无法形成关联洞察。用户需要在多个 App 之间跳转,数据永远无法交叉验证和深度分析。

  4. **行动与觉察脱节** — 即使知道问题所在,也缺乏从觉察到行动的系统化路径。看到"上周娱乐时间过多"的统计后,下一步该做什么?如何将洞察转化为可执行的改进计划?

* **为什么做这个方向:**

  **判断 1: AI 应该降低记录门槛,而非增加交互负担**

  市面上很多 AI 工具要求用户主动对话、输入 Prompt 才能获得价值,这本质上是把"手动记录"替换成了"手动提问"。LifePrism 的设计理念是**让 AI 在后台默默工作**——自动追踪时间、自动分类活动、自动关联目标,用户只需在需要时查看分析结果,或**通过微信随时随地与 AI 助手对话**。

  **判断 2: 数据联动比数据量更重要**

  不追求"记录一切",而是聚焦三个核心维度:**外在行为(LifeWatch)、目标管理(GoalMaster)、内在感受(Mind Space)**。这三者的交叉分析能回答最有价值的问题:目标进度与时间投入是否匹配?情绪波动与行为模式是否相关?计划拆解是否合理?

  **判断 3: 本地优先 + 开源,掌控感是信任的基础**

  个人时间和心理数据极其敏感,选择 Electron 桌面应用 + 本地 SQLite 数据库的架构,确保数据完全在用户掌控之中。开源协议(AGPL v3)保证透明性,用户可以审计代码、自行部署,甚至根据需求定制功能。AI 接口支持 OpenAI / DashScope / Google GenAI 多模型接入,用户可以选择信任的服务商。

  **取舍 1: 放弃移动端,专注桌面场景**

  虽然移动端能覆盖碎片时间,但深度工作、学习、创作主要发生在桌面环境。与其做一个"什么都能做但什么都不精"的全平台应用,不如把桌面端的自动追踪、数据可视化、目标管理做到极致。移动端的需求通过微信 Agent 助手部分覆盖——用户可以随时随地查询数据、记录心情,而无需完整的移动 App。

  **取舍 2: 先做"看见",再做"建议"**

  初期版本专注于**帮助用户建立清晰的自我认知**——通过可视化时间轴、旭日图、趋势折线图、习惯热力图等工具,让用户"看见"自己的行为模式和心理状态。AI 的角色是"数据整理者"和"洞察提炼者",而非"人生导师"。未来可以基于积累的数据训练个性化模型,提供更主动的行为干预建议,但前提是用户已经建立了对系统的信任和对自我的基本认知。
