# LifePrism -- TRAE 创意挑战赛参赛方案

## 1. 创意名称 + 创意介绍

### 创意名称

**LifePrism -- AI 驱动的自我量化与个人成长桌面应用**

### 想解决什么问题

人们在数字化时代花费大量时间在电脑上，却对自己每天的时间去向、行为模式和心理状态缺乏清晰认知。传统手动记录方式繁琐且难以坚持，而市面上的时间管理工具只追踪"你在用哪个软件"，无法回答"你在做什么、为什么做、感受如何"。

### 为什么会想到做这个

灵感来源于个人痛点 -- 每天坐在电脑前超过 10 小时，却说不出时间花在了哪里。现有的时间追踪工具（如 ActivityWatch、RescueTime）只能告诉你"今天用了 3 小时浏览器"，但无法理解你是在深度工作还是在无意义刷网页。我希望构建一个不仅能自动追踪行为、还能结合目标管理、习惯养成和心情记录的全息系统，让 AI 成为真正理解你生活节奏的伙伴。项目参考了接纳承诺疗法（ACT）的心理学框架，从觉察到行动，形成完整的自我成长闭环。

### 大概是什么产品

一款基于 Electron + React + Python FastAPI 的桌面端应用，集成了 AI 自动行为追踪（支持 OpenAI / DashScope / Google GenAI 多模型接入）、智能分类、目标管理、习惯养成、心情日记记录和多维度数据分析可视化，并支持通过微信远程交互的跨平台个人成长助手。

## 2. 目标用户及痛点

### 面向哪些用户

- **自由职业者和远程工作者**：缺乏外部约束，容易陷入时间黑洞，需要自我管理工具
- **学生群体（考研 / 考公 / 科研党）**：需要精确的时间管理来应对高强度学习任务，同时关注心理状态
- **自我成长爱好者**：关注生产力优化、习惯养成、心理健康的"量化自我"实践者
- **知识工作者和程序员**：长时间面对电脑，希望了解自己的工作模式并优化效率

### 在什么场景下使用

- **早晨规划**：打开应用，查看昨日 AI 自动生成的时间分析报告，安排今日任务
- **工作时**：桌面浮窗（What Am I Doing）实时显示当前活动，一键标记分类
- **碎片时间**：通过微信远程让 AI 帮你记录心情或查看近期状态
- **睡前回顾**：查看心情趋势图、习惯打卡热力图，撰写日记，AI 辅助生成每日总结
- **周 / 月末复盘**：查看旭日图、折线图统计，复盘目标完成度、时间投入分布

### 当前痛点

- **时间感知模糊**：无法精确知道每天的时间分配，"感觉忙了一整天但不知道忙了什么"
- **记录成本高**：手动记录时间、心情、习惯需要极强的自律，大多数人坚持不过一周
- **数据孤岛**：时间管理工具、习惯打卡 App、日记软件各自独立，无法形成关联洞察（比如"心情低落的日子是否与某个习惯中断有关"）
- **缺乏深度理解**：现有工具只停留在表面数据（用了什么 App），无法理解行为背后的上下文（在做什么、为了什么目标、感受如何）
- **行动与觉察脱节**：知道问题但缺乏从觉察到行动的系统化路径

## 3. 价值与意义

### 效率提升

LifePrism 通过 AI 自动分类和截图分析，将时间记录的门槛从"手动填写"降低到"全自动无感"，从根本上解决了时间追踪难以坚持的问题。结合目标管理四层架构（目标 → 计划书 → 任务池 → 日历），用户可以将宏大的愿景拆解为每日可执行的行动，并通过时间投入数据反向验证目标进度。旭日图、热力图、趋势折线图等多维度可视化，让用户一目了然地发现自己的效率模式和改进空间。这不是一个简单的"计时器"，而是一个从觉察到行动的完整效率闭环系统。

### 社会价值

在信息过载和注意力经济盛行的当下，帮助人们重新获得对自我时间和心理状态的掌控感，具有深远的社会意义。LifePrism 参考接纳承诺疗法（ACT）的心理学框架，不仅追踪外在行为，还关注内在感受（心情记录、日记、AI 对话），致力于帮助用户建立健康的自我认知和情绪管理能力。开源协议（AGPL v3）确保了项目的透明性和社区可贡献性，让更多人能够以低成本获得高质量的自我量化工具。
