## 一、产品概述

WAID（What Am I Doing）是一款独立桌面应用，核心解决 AI 多任务并行时代"初始目标丢失"的问题。本 PRD 描述 WAID 的完整功能设计，包括任务管理浮窗、计时记录、时间线回顾三大模块。

**产品定位**：个人行动日志 —— 记录"做了什么"与"怎么做的"，成为每日复盘的原始素材。

**独立项目说明**：WAID 为独立项目，不隶属于当前 LifeWatch-AI 仓库。但可参考 LifeWatch-AI 的 UI 风格（深色主题、Tailwind CSS）和部分实现模式（Timeline 竖向时间轴布局、CustomBlock 标签区设计）。

## 三、界面一：WAID 置顶浮窗

### 3.1 基本形态

- 无边框、始终置顶的桌面浮窗
- 高度自适应（120px ~ 600px）
- 深色主题（`#1e1e1e` 底色，翠绿色标题栏 `#10b981 → #14b8a6`）
- 参考实现：`LifeWatch-AI/frontend/floating/what-am-i-doing/`

### 3.2 任务列表

- 支持树形结构（父子层级 + 折叠/展开）
- 支持拖拽排序（同层级内）
- 每个任务行显示：拖拽手柄、折叠箭头、checkbox、任务名称、类型圆点（新增）、时长、计时按钮

### 3.3 子任务类型（新增核心功能）

子任务分为 **3 种类型**：

| 类型 | 颜色 | 含义 | 默认 |
|------|------|------|------|
| `blocking` | 🔴 `#ef4444` | 阻塞项：必须完成才能推进主任务 | ✅ 新建子任务默认 |
| `optimize` | 🟢 `#22c55e` | 优化项：锦上添花，可跳过，先记录 | |
| `prereq` | 🟡 `#f59e0b` | 前置项：依赖另一个任务，跨任务链接 | |

**视觉表现**：任务名称左侧、checkbox 右侧，显示 8px 直径圆点。

**类型切换**：在任务右侧 `···` 菜单中增加类型切换子菜单（含圆点预览）。

### 3.4 前置依赖链接（prereq 专属）

当任务类型设为 `prereq` 时，需绑定一个被依赖的目标任务。

**操作入口**：`···` 菜单中：

```
┌─────────────────┐
│  Remove          │
│  ──────────────  │
│  创建链接项       │  ← 新建同级任务 B，A3 自动绑定到 B
│  链接到现有项     │  ← 弹出搜索面板，选择已有任务绑定
└─────────────────┘
```

- **创建链接项**：在同级（与父任务同级）创建一个新的根级任务 B，当前子任务的 `blocked_by` 字段自动指向 B。B 的内容为空白，等待用户填写。
- **链接到现有项**：弹出一个搜索/选择面板，从已有任务中选择绑定目标。

**视觉表现**：prereq 类型圆点（🟡）悬停时，显示 Tooltip：

```
┌─────────────────────┐
│ 🔗 被阻塞于：        │
│ 看懂认证流程          │
│ 点击跳转 →           │
└─────────────────────┘
```

点击 Tooltip 中的链接，滚动并高亮目标任务。当被依赖任务完成后，圆点颜色可从 🟡 变为 ⚪（表示前置条件已满足）。

### 3.5 计时控制

- 每个任务行 hover 时显示 ▶ 播放按钮
- 计时中显示红色停止按钮 + 绿色脉冲圆点 + 实时已过时间
- 全局互斥：同时只有一个任务在计时
- 数据通过 `navigator.sendBeacon()` 在窗口关闭时保活

## 四、界面二：确认弹窗（计时结束后弹出）

### 4.1 触发条件

计时器停止时（手动点击停止 / 任务完成），弹出确认框。

### 4.2 布局

```
┌─────────────────────────────────────────────────────┐
│  ✅ 任务完成 · 确认记录                              │
│                                                     │
│  ┌─ 时间 ──────────────────────────────────────┐    │
│  │  开始时间  [14:30]    结束时间  [15:45]       │    │
│  └─────────────────────────────────────────────┘    │
│                                                     │
│  ┌─ 子任务 ────────────────────────────────────┐    │
│  │  ☑ A1 复现 bug                    🔴       │    │
│  │  ☑ A2 定位原因                    🔴       │    │
│  │  ☐ A3 修复 token 刷新             🟡 → B   │    │
│  │  ☑ A4 重构 auth 命名              🟢       │    │
│  └─────────────────────────────────────────────┘    │
│                                                     │
│  ┌─ 复盘 ──────────────────────────────────────┐    │
│  │  [                                   ]       │    │
│  │  token 刷新定位到了 cookie 问题，            │    │
```

### 4.3 三区域说明

| 区域 | 内容 | 交互 |
|------|------|------|
| **时间** | 开始/结束时间，默认自动填充计时起止 | 支持手动修改 |
| **子任务** | 该任务下的所有子步骤列表，带类型圆点（只读展示） | 支持勾选完成/未完成 |
| **复盘** | 自由文本区域 | 多行 textarea，记录思考、问题、遗留事项 |

### 4.4 提交后

- 数据保存为一条 `TaskExecutionRecord`
- 时间线主页即时刷新，新增对应色块

### 5.2 任务色块结构

每个记录的时间块具备以下结构：

- **左侧标签区**：圆角矩形卡片，显示任务名称 + 时长。样式参考现有 Timeline 的 CustomBlock 标签。
- **右侧子任务区**：纵向排列该记录包含的子任务。每行格式：

```
[a1]  [复现 bug]                    [🔴]
  ↑          ↑                       ↑
分点标识   子任务名称              类型颜色块
(等宽小标签)                      (仅颜色，不可交互)
```

- **无子任务时**：右侧子任务区为空，色块高度缩小为紧凑单行。

### 5.3 颜色规则

| 元素 | 颜色 |
|------|------|
| 深色主题底色 | `#1e1e1e`（与浮窗一致） |
| 任务标签卡 | 白色 / 浅色圆角矩形，翠绿色文字 |
| 色块背景 | 深灰底色 + 微弱类型色叠加 |
| 子任务文字 | 白色 |
| 类型圆点 | 🔴 blocking / 🟢 optimize / 🟡 prereq |
| 已完成子任务 | 删除线 + 半透明 |

### 5.4 交互

- **Ctrl + 滚轮**缩放时间轴高度（与现有 Timeline 相同）
- **点击色块** → 右侧展开详情面板
- **日期导航**：左右箭头 + 日期选择器

## 七、截图功能

### 7.1 配置

| 配置项 | 说明 | 默认值 |
|--------|------|--------|
| 截图开关 | 是否启用自动截图 | 关闭 |
| 截图间隔 | 每隔多少秒截一次 | 60s |
| 截图存储路径 | 截图文件存放目录 | 用户数据目录/screenshots/ |

### 7.2 运行逻辑

1. 用户在浮窗中启动任务计时 → 若截图开关打开，后台按间隔自动截屏
2. 截图以 `{taskId}_{timestamp}.png` 命名，保存到指定目录
3. 计时结束时，截图文件路径数组随 `TaskExecutionRecord` 一起保存
4. 在时间线详情面板的"截图"Tab 中按时间戳顺序展示

### 7.3 生命周期

- 截图与任务执行记录绑定
- 删除任务记录时，弹窗询问是否同时删除关联截图
- 用户可手动删除单张截图（在详情面板中操作）

## 八、数据模型

### 8.1 TodoItem（扩展现有）

```typescript
interface TodoItem {
  id: string
  content: string
  parentId: string | null
  state: 'pool' | 'scheduled' | 'completed' | 'shelved'
  orderIndex: number

  // 新增字段
  todoType: 'blocking' | 'optimize' | 'prereq'  // 默认 'blocking'
  blockedBy: string | null                        // prereq 专属，指向被依赖任务 ID
  children?: TodoItem[]
}
```

### 8.2 TaskExecutionRecord（新增）

```typescript
interface TaskExecutionRecord {
  id: string
  taskId: string                     // 关联 TodoItem
  taskContent: string                // 任务名称（冗余，便于显示）
  startTime: string                  // ISO datetime
  endTime: string                    // ISO datetime
  duration: number                   // 秒
  subtaskSnapshots: SubtaskSnapshot[] // 子任务完成快照
  review: string                     // 复盘文本
  screenshotPaths: string[]          // 截图文件路径数组
}

interface SubtaskSnapshot {
  subtaskId: string
  content: string
  todoType: 'blocking' | 'optimize' | 'prereq'
  blockedBy: string | null
  completed: boolean
  orderIndex: number
}
```

### 8.3 ScreenshotItem（新增）

```typescript
interface ScreenshotItem {
  id: string
  recordId: string         // 关联 TaskExecutionRecord
  filePath: string         // 文件路径
  timestamp: string        // 截图时间
  note: string             // 用户备注
}
```

## 九、功能优先级

### P0：MVP 核心闭环

- [ ] 置顶浮窗：任务 CRUD + 树形结构 + 拖拽排序
- [ ] 子任务类型标记（3 种 + 颜色圆点）
- [ ] 计时启停 + 确认弹窗（时间 + 子任务勾选 + 复盘）
- [ ] 时间线主页：竖向时间轴 + 任务色块展示
- [ ] 数据持久化（任务 + 执行记录）

### P1：增强体验

- [ ] 前置依赖链接（创建链接项 / 链接到现有项）
- [ ] 右侧详情面板：复盘 Tab（编辑 + 重新勾选）
- [ ] Tooltip 悬停显示依赖关系

### P2：截图与高级功能

- [ ] 截图 Tab：缩略图网格 + 大图预览 + 备注
- [ ] 自动截图（计时中按间隔截屏）
- [ ] 任务执行记录的删除与编辑

## 十、技术选型建议

| 层面 | 建议 | 理由 |
|------|------|------|
| 桌面框架 | Electron | 与 LifeWatch-AI 一致，支持置顶浮窗、系统托盘 |
| 前端框架 | React + TypeScript + Vite | 与 LifeWatch-AI 一致 |
| 样式 | Tailwind CSS | 快速构建暗色主题 |
| 拖拽 | @dnd-kit/core | 与现有 WAID 浮窗一致 |
| 截图 | Electron `desktopCapturer` | 原生桌面截屏 |
| 数据存储 | SQLite（本地） | 单机应用，无需服务端 |
