## Acceptance criteria

- [ ] 在 `templates/agent/chat/tool.md` 的"控制指令"部分之前，新增"会话切换辅助"章节

### 章节内容要求

- [ ] **工具介绍**：
  - [ ] 说明 `query_session_list` 工具的用途：查询会话列表，包含最新总结和最后消息
  - [ ] 说明 `query_session_history` 工具的用途：查看指定会话的最近对话
  - [ ] 明确适用场景：用户想切换到之前的会话，但不确定是哪个

- [ ] **引导流程**：
  - [ ] 第一步：AI 主动询问用户
    - 上次操作内容是什么？
    - 时间范围是什么？
  - [ ] 第二步：根据用户回答调用工具
    - 用户不确定内容，或只说了时间 → 调用 `query_session_list`
    - 用户对某个会话仍不确定 → 引导使用 `query_session_history`

- [ ] **列出结果的格式要求**：
  - [ ] 必须有明确序号：第1个、第2个、第3个...
  - [ ] 每项显示：session_id、最新总结、最后消息
  - [ ] 等待用户选择，不自动切换

- [ ] **用户选择后的响应模板**：
  - [ ] 识别用户说的"第X个"或模糊描述
  - [ ] 回复格式：
    ```
    请复制下面的指令发送
    /continue <session_id>
    ```
  - [ ] 不要只说 session_id，要生成完整的可复制指令

- [ ] **示例对话**（可选，但推荐）：
  - [ ] 提供一个完整的示例对话流程
  - [ ] 展示 AI 如何询问、调用工具、列出结果、生成指令

### 验证（HITL）

- [ ] 通过微信进行实际对话测试：
  - [ ] 场景1：用户说"我想回到之前的会话"
    - [ ] AI 是否主动询问时间和内容？
    - [ ] AI 是否调用了 `query_session_list` 工具？
    - [ ] AI 是否按序号列出结果？
  - [ ] 场景2：用户说"第2个"
    - [ ] AI 是否识别出用户选择的是第2个？
    - [ ] AI 是否回复了完整的 `/continue <session_id>` 指令？
  - [ ] 场景3：用户说"应该是关于前端开发的那个"
    - [ ] AI 是否能从列表中匹配最符合的项？
    - [ ] AI 是否生成了正确的切换指令？

- [ ] 根据实际测试效果，迭代优化提示词措辞
  - [ ] 如果 AI 不询问时间，增强"第一步"的指令强度（使用"必须"）
  - [ ] 如果 AI 不按序号列出，明确"必须有明确序号"
  - [ ] 如果 AI 不生成完整指令，提供更明确的模板示例
