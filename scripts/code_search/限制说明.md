# 代码搜索工具限制说明

## func_search.py (grep 方案)

### 当前实现

- **定义搜索**：grep `def func_name` → 向上找 `class` → 拼出完整路径
- **调用搜索**：grep `func_name(` → 向上找 `def` → 得到调用方函数名

### 限制

**调用搜索无法按类过滤**

当搜索 `ClaudeExecutor.execute` 时：
- 定义：能正确过滤，只返回 `ClaudeExecutor` 类内的 `execute`
- 调用：显示所有 `execute(` 的调用，包括 `Agent.execute`、`DockerExecutor.execute` 等

原因：调用方写的是 `executor.execute()` 或 `self.execute()`，grep 无法判断 `executor` 是什么类型。

### 解决方案

要做到精确的调用链分析，需要：
1. **类型推断工具**：pyright / pylance
2. **AST + 启发式匹配**：结合 AST 的定义数据，猜测调用关系

## ast_scanner_tree.py (Tree-sitter 方案)

### 当前实现

- 使用 Tree-sitter 解析 AST
- 记录函数定义和调用关系

### 限制

**无法追踪变量方法调用**

当代码写 `group_chat.send_message_to_agent(message)` 时：
- `group_chat` 是变量，Tree-sitter 不知道它是什么类型
- 因此无法记录这个调用关系

### 解决方案

1. **类型推断工具**：pyright / pylance
2. **grep 补充**：用 grep 搜索变量方法调用（func_search.py 的方案）
