# LifePrism 用户使用指南 📖

> **本文档为用户提供完整的功能参考，介绍 LifePrism 的各项功能及使用方法。**

---

## 1. 项目概述

LifePrism 是一个 AI 驱动的生活记录与目标管理系统，通过 AI 技术实现时间、目标与自我认知的深度融合，构建“数据-分析-执行”的闭环。

### 核心能力（已上线）
- **全渠道数据采集**：整合多种数据来源通道。目前主要支持电脑端，通过 ActivityWatch 收集数据。
- **AI 智能分类与可视化**：自动处理原始数据，识别应用用途（如学习、工作、娱乐等），并生成旭日图、柱状图、时间线等直观图表。
- **目标驱动系统**：模块化管理个人目标与执行进度。
- **AI 交互对话**：提供基于上下文的智能助手服务，回答问题并提供个性化建议。

### 长期愿景
LifePrism 旨在进化为支持自我察觉、深度反思、自我定义与自我关怀的伙伴，参考 **接纳承诺疗法（ACT）** 六角模型：
- **认知与存在层面**：通过“AI 日记”与“对话”辅助用户实现认知解离与接纳，引导用户观察而非陷入情绪。
- **觉察层面**：帮助用户接触当下，建立观察者视角，从繁杂数据中审视生命全景。
- **行动层面**：将目标管理与价值导向绑定，确保每一项行动都指向内心的价值方向。

### 数据处理流向
1. **ActivityWatch**：原始数据采集（需安装并运行）。
2. **后端处理**：进行数据清洗、标准化。
3. **AI 分类层**：
    - **第0步：缓存匹配**：检查 Map Cache，命中则直接使用，成本为零。
    - **第1步：Goal 匹配**：检查是否与目标关联，若关联则优先使用目标分类。
    - **第2步：AI 分类**：调用 LLM 判断。单用途应用存入缓存；多用途应用（如浏览器）结合标题深度分析。
4. **存储与展示**：存入 SQLite 数据库，由 React 前端呈现。

## 2. 界面功能详解

### 🏠 首页 (HomePage)
首页提供当日活动概览及数据同步。
- **Activity Summary (活动趋势图)**：
    - 展示过去 14 天趋势。
    - **柱形图交互**：点击任意柱形可切换查看该日期的详细数据。
    - **refresh 按钮**：增量同步。从数据库最新记录同步到当前，速度快。
    - **sync Data 按钮**：范围同步。可指定起止日期，会覆盖已存在的数据。
    - **filter 按钮**：按分类筛选显示特定的时间趋势。
- **Today's Focus (待办事项)**：
    - 显示当日任务。点击右侧的 **">"** 号可跳转到 Goals 页面的每日任务视图。
- **Time Overview (时间概览)**：展示当日旭日图和按小时分布的柱状图。
- **Activity Details (活动详情)**：
    - **Top Apps**：按时长降序排列的应用列表。
    - **Top Titles**：频率最高的窗口标题列表。

### ⏳ 时间线 (TimeLine)
按时间顺序展示详细记录，支持缩放和备注。
- **顶部工具栏**：
    - **数据源筛选**：目前固定为 All Sources。
    - **缩放控制**：在主轴滚动鼠标滚轮可放大/缩小视图。
    - **过滤按钮**：设置时长阈值（分钟），隐藏短时间碎片。
    - **缩略图开关**：切换色块概览与详细列表。
- **缩略图模式**：
    - **时间段下拉**：选择粒度（如 1 小时、30 分钟）。
    - **分类下拉**：选择查看主分类或子分类层级。
    - **Top N**：选择显示前 N 个分类，其余归为“其他”。
    - **交互**：点击色块，右侧显示该时段的旭日图和统计。
- **详细视图模式**：
    - **时间块交互**：点击时间块查看应用名、标题、时长等详情。
    - **分类修改**：在右侧面板手动修正主/子分类，修改后自动保存。
- **自定义备注**：
    - **添加**：鼠标移至左侧标签区，点击出现的 **"+"** 号。
    - **编辑**：点击备注块，可设置内容、颜色、时间范围，并**绑定待办事项、主/子分类**。
    - **显示**：以半透明色块显示，左侧有颜色标识线。

### 📂 分类管理 (Category)
管理分类体系与 AI 分类逻辑。
- **Category Settings (分类设置)**：
    - **颜色选择**：主分类选色，子分类自动生成同色系。
    - **禁用/启用**：禁用后 AI 不再使用，且 Map Cache 同步禁用。启用时若有冲突，优先恢复原有缓存。
    - **删除/修改**：支持分类重命名和级联删除。
- **Data Review (数据审核)**：
    - 审核 AI 结果。支持**单条修改**和**多选批量修改/删除**。
- **Map Cache (映射缓存)**：
    - **单用途 vs 多用途**：单用途按应用名匹配；多用途（如 Chrome）按应用名+标题匹配。
    - **同步到日志**：修改映射后，可一键更新所有历史记录。

### 🎯 目标管理 (Goals)
核心枢纽，支持单/双栏布局联动。
- **目标视图 (Goal)**：
    - **目标列表**：展示状态、主题色、投入时长。
    - **目标详情**：配置关联分类、起止日期、承诺与价值观。
    - **里程碑**：可拖拽排序、点亮完成。
    - **日志**：记录进展并选择心情标签（喜悦/平静等）。
    - **分类绑定（核心）**：每个目标绑定一个分类。AI 分类时会**优先匹配目标上下文**。
- **计划书 (PlanDoc)**：
    - **编辑器**：Markdown 编写。
    - **任务块语法**：使用 `<!-- lp:todoblock -->` 包裹的任务（- [ ]）才会被同步。
- **任务池 (Task Pool)**：
    - **状态**：`pool` (待分配)、`scheduled` (已安排)、`completed` (已完成)。
    - **同步**：从计划书解析新任务并写回锚点。
- **任务分配 (Calendar)**：
    - **拖拽**：从任务池拖到日历格子，状态变为 `scheduled`。
- **每日任务 (Daily)**：
    - **执行**：设置预期结束时间、记录拖延原因。
    - **联动**：完成任务自动回写计划书（[ ] 变为 [x]）。

## 3. 常见问题 (FAQ)

- **Q: 误删数据？** A: 首页使用 `Sync Data` 重新同步即可恢复。
- **Q: AI 分类不准？** A: 建议在 `Map Cache` 修改映射并点击“同步到日志”。
- **Q: 计划书修改后任务池没变？** A: 需要**手动点击同步按钮**。
- **Q: 如何追踪目标的历史数据？** A: 在 `Map Cache` 设置软件的 `link_to_goal`，然后重新同步数据。
- **Q: 一个软件能绑多个目标吗？** A: 单用途软件在同一时段只能绑一个，但可以通过在不同日期范围同步时修改 `link_to_goal` 来实现分段统计。

## 🛠️ 系统配置 (Settings)

- **AI 配置**：设置服务商、API Key、模型、Token 单价。
- **分类逻辑**：设置“长活动”阈值（超过该时长使用复杂分类逻辑）。
- **存储与迁移**：支持将数据库、计划书等迁移至新路径。迁移后需重启。
- **数据清洗**：设置短时过滤阈值（秒），自动剔除无意义碎片。
