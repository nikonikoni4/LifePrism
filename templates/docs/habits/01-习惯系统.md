## 页面布局

Habits 页面采用左侧边栏 + 右侧主区的布局：

**左侧边栏**：时间线（Timeline），按时间顺序展示习惯链条中的节点及打卡状态。

**右侧主区**，从上到下分为：
1. **顶部概览行**：今日打卡进度 + 12周热力图 + 4周趋势图
2. **底部三栏**：时间线详情 / 习惯链条 / 习惯列表

习惯列表顶部有筛选下拉菜单（全部 / 激活习惯 / 暂停习惯）和"新建习惯"按钮。

---

## 1. 创建习惯

点击 **"+ 新建习惯"** 按钮，弹出创建对话框，填写以下信息：

| 字段 | 说明 |
|------|------|
| 习惯名称 | 必填，1-100 字符 |
| 习惯描述 | 可选，最多 500 字符 |
| 打卡频率 | daily（每天）/ weekdays（工作日）/ weekend（周末）/ custom（自定义星期几） |
| 关联的价值/承诺 | 可选，关联 Mind Space 中的价值和承诺 |

创建后系统自动完成两件事：
1. 习惯状态变为 **active（激活）**
2. 自动创建该习惯的**首个挑战**，状态为 **进行中（in_progress）**

---

## 2. 习惯卡片

每个激活中的习惯以卡片形式展示在习惯列表中，卡片上包含：

| 元素 | 说明 |
|------|------|
| **习惯名称** | 用户创建时设定的名称 |
| **频率标签** | 如"每天"、"工作日"等 |
| **锚点标签** | 如果习惯关联到习惯链条的节点，显示锚点名称和时间 |
| **Lv.X** | 当前等级（0~4） |
| **🔥 N** | 连续打卡天数（火焰图标） |
| **进度条** | 当前挑战的完成进度（已完成/总天数），红色标记表示最低达标线 |
| **剩余休息日** | 当前挑战还可休息的天数 |
| **CHECK IN / DONE 按钮** | 今日打卡操作按钮 |

暂停中的习惯则以 **PausedHabitCard** 展示，样式与激活卡片不同，没有打卡按钮，显示"已暂停"状态。

---

## 3. 频率设置

习惯的打卡频率在创建时设定，也可以在编辑时修改，有以下四种选项：

| 频率 | 说明 | 一周应打卡天数 |
|------|------|---------------|
| **每天（daily）** | 每天都需打卡 | 7天 |
| **工作日（weekdays）** | 周一至周五打卡 | 5天 |
| **周末（weekend）** | 周六和周日打卡 | 2天 |
| **自定义（custom）** | 自由选择每周的特定日期 | 所选天数 |

**注意**：频率定义的是"推荐打卡日程"，并非硬约束——你可以在非应打卡日也进行打卡，同样会计入挑战完成次数。

---

## 4. 等级系统

习惯采用 **0~4 级渐进式等级系统**，名称与含义如下：

| 等级 | 名称 | 含义 | 挑战周数 | 85% 最低完成天数（daily频率） |
|------|------|------|----------|-------------------------------|
| Lv.0 | 萌芽 | 刚开始尝试 | 2周 | 12天（14×85%） |
| Lv.1 | 生根 | 初步建立 | 3周 | 18天（21×85%） |
| Lv.2 | 成长 | 逐渐稳固 | 4周 | 24天（28×85%） |
| Lv.3 | 稳固 | 已成为习惯 | 8周 | 48天（56×85%） |
| Lv.4 | 根深蒂固 | 长期稳定 | 12周 | 72天（84×85%） |

**规则：**
- 等级越高，挑战周期越长（从2周到12周），要求也越高
- **升级**：当前挑战成功 → 等级+1，最高到 Lv.4
- **维持**：Lv.4 后不再升级，但会继续创建同等级挑战来维持习惯
- **失败**：挑战失败时等级不变，停留在当前等级

## 5. 挑战机制

挑战（Challenge）是习惯系统的核心——每个习惯始终有一个**当前挑战**，挑战成功则习惯升级。

### 挑战参数计算

挑战的难度由**等级 × 频率**共同决定：

```
每周应打卡天数 = 由频率决定（daily=7, weekdays=5, weekend=2, custom=所选天数）
总预期天数 = 挑战周数 × 每周应打卡天数
最低完成天数 = ceil(总预期天数 × 85%)
```

例如：daily 频率的 Lv.0 挑战，2周总共14天，需要至少完成 **12天**（85%）才算成功。

### 打卡成功标准

点击卡片上的 **CHECK IN** 按钮进行今日打卡。打卡成功需要满足：
1. 习惯状态为 **激活中（active）**
2. 当前挑战状态为 **进行中（in_progress）**
3. 今天尚未打卡（同一天不能重复打卡）

打卡成功后：
- 挑战的已完成次数 +1
- 重新计算连续打卡天数（Streak）
- 执行挑战结果判定

### 挑战结果判定

判定在每次打卡和系统定时检查时执行：

| 结果 | 条件 | 后续操作 |
|------|------|---------|
| **succeeded（成功）** | 到达挑战结束日期，且已完成次数 ≥ 最低要求 | 自动升级等级（+1），创建下一等级新挑战，继承当前 Streak |
| **failed（失败）** | 数学上不可能完成（剩余天数不够补足差额） | 挑战标记为 failed，等级不变，生成待处理结算条目，等待用户操作 |
| **in_progress（进行中）** | 日期未到或已完成但日期未到 | 继续等待 |

**注意**：挑战成功必须等到结束日期到达；但**失败可以提前判定**——当剩余可打卡天数不足以补足差额时，系统会提前判定失败。

## 6. 状态机

### 习惯状态（2种）

```
创建 → active（激活）
         ↓ 手动暂停 / 挑战失败后选择暂停
      paused（暂停中）
         ↓ 用户点击恢复
      active（激活）
```

### 挑战状态（4种，单向不可逆）

```
in_progress（进行中）
    ├── 到达结束日期且达标 → succeeded（成功）- 作为历史记录保留
    ├── 不可能达标 → failed（失败）- 作为历史记录保留
    └── 手动暂停/修改等级或频率 → cancelled（取消）- 不作为历史记录
```

**关键规则：**
- 挑战状态一旦离开 in_progress 即终结，后续操作会创建新挑战
- succeeded 和 failed 的挑战在 **挑战历史** 中可查看
- cancelled 的挑战不保留历史记录

---

## 7. 暂停与恢复

### 暂停习惯

点击习惯卡片右上角的菜单 → "暂停"，会：
1. 当前挑战标记为 **cancelled**
2. 习惯状态变为 **paused**
3. 连续打卡基数归零（恢复后重新累计）

**暂停后打卡按钮不可用**，无法进行打卡操作。

### 恢复习惯

点击暂停习惯卡片的恢复按钮，会：
1. 创建**同等级**的新挑战，连续打卡基数归零
2. 习惯状态恢复为 **active**
3. 可以正常打卡

---

## 8. 连续打卡（Streak）与火焰图标

习惯卡片上的 **🔥 N** 表示当前连续打卡天数。它是习惯养成坚持度的重要指标。

### daily 频率的 Streak 计算

- **每次打卡当天** → Streak +1
- **某天未打卡** → Streak 立即归零（断链）
- **今天还没打卡** → 不算断链，从昨天开始回溯计算
- 如果一直未断链回溯到挑战开始日期 → 加上历史累计的连续打卡天数

**示例：** 如果你连续打卡 5 天，第 6 天没打，第 7 天再打时 Streak 从 1 重新开始。

### 非 daily 频率的 Streak 计算

- **按天累加**：每次打卡当天 Streak +1（当天未打卡不会归零）
- **中断判定时点**：只在**周一**结算上一自然周（周一至周日）
- **结算规则**：如果上周打卡次数 < 上周目标次数，则 Streak 清零
- 当前周只做实时累加，不触发失败结算

### 火焰图标消失条件

火焰图标（🔥+数字）在以下情况会消失：
1. **Streak 归零时**（连续打卡断链）：图标变为不显示或数字变为 0
2. **挑战失败后重新开始时**：新挑战的连续打卡归零

### Streak 跨挑战延续

- **挑战成功**：新挑战继承当前连续打卡天数作为基础值
- **挑战失败/取消**：新挑战的连续打卡归零
- **补签恢复**：补签可能修复断链，Streak 会重新计算

---

## 9. 补签

如果某天忘记打卡，可以在**滚动 7 天窗口内**进行补签。

### 操作路径

点击习惯卡片右上角的菜单 → "补录近7天"，或从挑战结算弹窗中点击"补录近7天"。

### 补签规则

| 条件 | 说明 |
|------|------|
| 时间窗口 | 只能补今天之前最多 6 天内的日期（today-6 ~ today-1） |
| 挑战状态 | 当前挑战必须为 **进行中（in_progress）** |
| 日期范围 | 补签日期必须在挑战周期内（不早于挑战开始日期） |
| 唯一性 | 已打卡的日期不能重复补签 |

### 补签的作用

- 补签后挑战的已完成次数增加
- **可能修复断链**：如果断链是因为漏打卡导致的，补签后 Streak 重新计算，可能恢复连续打卡
- 补签后系统重新执行挑战结果判定

---

## 10. 挑战结算

当挑战被判定为失败时，不会立即修改数据库状态，而是生成**待处理结算条目**，等待用户操作。

结算弹窗中展示所有待结算的习惯，每个条目显示：
- 习惯名称和图标
- 等级变化（如 Lv.0 → Lv.0）
- 失败标签
- 完成进度（如 完成 0/6 天 (0%)）

用户对每个习惯有 **三种选择**：

| 操作 | 效果 |
|------|------|
| **补录近7天** | 打开补签窗口补录漏打卡的日期，补录后重新判定 |
| **重新开始当前挑战** | 将当前挑战标记为 failed，创建同等级新挑战，从头开始 |
| **暂停习惯** | 将当前挑战标记为 failed，习惯状态改为 paused，暂停打卡 |
| **稍后处理** | 不改变任何状态，下次进入 Habits 页面会再次弹出结算 |

如果用户不处理结算条目，习惯卡片上会持续显示结算状态提示。

## 11. 习惯链条

### 概念

习惯链条（Habit Chain）是基于**习惯堆叠心理学**的设计——用已养成的习惯（锚点）来触发和养成新习惯。例如："吃完午饭后 → 吃药"。

### 组成

习惯链条由一组**有序的节点**组成。每个节点可以是：
- **锚点节点**：关联了一个已有习惯的节点
- **纯锚点节点**：未关联习惯，仅作为时间/事件标记（如"中午午饭后"）

### 作用

- 将零散的习惯按时间/事件顺序串联起来，形成固定流程
- 通过锚点（已有习惯）触发新习惯，降低执行阻力
- 在 Timeline 中可视化展示一天的"习惯流程"

### 可设置在链条上的信息

- 节点名称（如"中午午饭后"、"中午-吃药"）
- 关联的习惯（将习惯绑定到该节点）
- 触发时间（可选，设置显式触发时间）

---

## 12. Timeline 时间线

### 位置

Habits 页面的**最左侧**，有一个垂直的时间线面板。

### 作用

Timeline 展示**启用了"在时间线显示"的习惯链条**中所有节点及其今日打卡状态：

| 元素 | 说明 |
|------|------|
| 节点名称 | 如"中午午饭后"、"中午-吃药" |
| 节点时间 | 显示用户设置的触发时间或后端自动计算的时间 |
| 打卡状态 | 已打卡的节点显示绿色勾选图标，未打卡的显示灰色圆点 |
| 待完成提示 | 如"+3 pending steps"表示还有几个节点待完成 |

### 时间计算规则

Timeline 中节点的时间有两种来源：
- **显式设置的时间**：用户为节点手动设置的时间
- **自动计算的时间**：后端根据节点之间的间隔自动推导的时间，计算规则如下：
  - 所有节点都无显式时间：按默认间隔（30分钟）从 00:00 开始递推
  - 有显式锚点时间：锚点之间的节点平均分配时间，锚点前后的节点向前/向后递推

---

## 13. 统计概览

### 今日打卡

- **应打卡数**：所有激活中的习惯中，今天属于应打卡日的数量
- **已完成数**：今天已打卡的习惯数量
- 计划外打卡不计入分母（只计入分子）

### 12周热力图

- 统计单位：每日
- 颜色越绿表示完成率越高，灰色表示未打卡
- 当日完成率 = 实际打卡数 ÷ 应打卡习惯数
- 包含计划外打卡

### 4周趋势图

- 横轴：第 1~4 周
- 纵轴：完成率百分比
- 每周完成率 = 所有激活中的习惯该周完成率的算术平均值

## 14. 习惯 Tips（INSIGHT）

页面左侧的 INSIGHT 卡片展示习惯养成建议，滚动切换显示。常见 Tips 包括：
- 当你不想做时，执行"最小版本"
- 成为"做那种事的人"
- 用"习惯链条"串联你的早晨或晚间
- 设计你的环境，而非依赖毅力
- 允许暂停，但不要删除
- 给你的习惯一个"为什么"
- 从"小到不可能失败"开始
- 找到你的"锚点"，而不是创造时间

---

## 15. 删除习惯

**操作：** 习惯卡片右上角的菜单 → "删除"（需二次确认）

**删除效果：**
- 硬删除：习惯相关的打卡记录、挑战记录全部级联删除
- 习惯链条处理：关联该习惯的链条节点，其习惯关联被解除，节点降级为纯锚点（不删除节点本身）
- 无论习惯是激活中（active）还是暂停中（paused），均可直接删除

## 常见操作

### 怎么创建一个新的习惯？

点击习惯列表右上角的 **"+ 新建习惯"** 按钮，填写名称和频率后确认即可。

### 习惯的 level 是什么意思？

Level（等级）表示习惯的巩固程度，从 Lv.0（萌芽）到 Lv.4（根深蒂固）。等级越高，挑战周期越长，说明该习惯已经融入日常生活。每次成功完成一个挑战，等级+1。

### 打卡成功的标准是什么？

打卡完成后，系统会检查当前挑战是否满足成功条件：**到达挑战结束日期** 且 **已完成次数 ≥ 最低要求（总预期天数的85%）**。两者同时满足才算挑战成功。

### 火焰图标旁边的数字代表什么？什么情况会消失？

🔥旁边的数字表示**连续打卡天数**。如果某天忘记打卡（daily 频率），连续打卡就会断链归零，图标消失。非 daily 频率则是在周一结算上周时判定是否断链。

### "习惯链条"是什么？

习惯链条是把多个习惯按时间/事件顺序串联起来的工具，基于"习惯堆叠"心理学——用一个习惯触发下一个习惯。比如："中午午饭后 → 吃药 → 休息"。链条可以在 Timeline 中可视化展示。

### 左侧的 Timeline 是干什么的？

Timeline（时间线）展示你今天所有习惯的流程安排。可以看到每个节点的触发时间、名称，以及哪些已经完成（绿色勾选）、哪些待完成。

### 暂停习惯会有什么影响？

暂停后不能再打卡，当前挑战被取消，连续打卡归零。恢复后会创建一个同等级的新挑战重新开始。

### 挑战成功后会发生什么？

等级+1（Lv.4 保持），自动创建下一等级的新挑战，连续打卡天数继承到新挑战中。

### 挑战失败了怎么办？

系统弹出结算弹窗，你可以选择：补录近7天（挽救）、重新开始当前挑战、或暂停这个习惯。

### 补签能修复断链吗？

可以。如果断链是因为漏打卡造成的，补签后 Streak 重新计算，可能恢复连续打卡状态。

### Lv.4 之后还能升级吗？

不能。Lv.4（根深蒂固）是最高等级，之后会继续创建同等级维持挑战，帮助你保持习惯。
