# 目标管理

> Goals 页面覆盖"目标 → 计划书 → 任务池 → 日历 → 每日任务"的完整工作流。支持双栏和单栏两种布局。

## 页面布局

**双栏布局（默认）** — 四个组合选项卡，左右面板联动：

| 选项卡 | 左侧面板 | 右侧面板 |
|--------|---------|---------|
| 目标 — 计划 | 目标列表 | 计划书编辑 |
| 计划 — 任务 | 计划书编辑 | 任务池 |
| 任务 — 日历 | 任务池 | 日历（可拖拽） |
| 日历 — 每日 | 日历 | 每日任务 |

**单栏布局** — 点击导航栏右侧的单栏/双栏图标切换。选项卡变为五个独立视图：目标 / 计划书 / 任务池 / 任务分配 / 每日任务。

左右箭头可循环切换选项卡。

---

## ① 目标 — 计划

### 左侧：目标列表

**添加目标：** 点击"添加新目标"按钮，在弹出的框中填写：
- 目标名称（必填）
- 目标简介（可选）
- 配置与主题（可选）：选择卡片主题、分类、开始/目标日期

创建后目标卡片显示在列表中，展示分类标签、名称、已投入时间、已进行天数、日期范围。

**查看目标详情：** 点击目标卡片展开全屏面板，可编辑：
- 标题和目标简介
- 配置：主题颜色、分类、开始/目标日期、自动跟踪/手动记录
- 里程碑（见下方）
- 日志：添加心情标签（开心/平静/沮丧/一般）

**标记完成/进行中：** 点击卡片右下角的勾选按钮切换。

**删除目标：** 悬停卡片点击垃圾桶图标，确认后关联的计划书和任务也会被一并删除。

**刷新投入时间：** 绑定分类并开启自动跟踪后，点击卡片上的刷新按钮可重新计算累计投入时间。

### 里程碑

在目标详情面板中，点击"编辑"打开里程碑编辑器：
- 添加/删除里程碑项
- 拖拽调整排序
- 保存后在水平轴线上展示

点击里程碑上的圆点切换完成状态。

### 分类绑定

在目标详情的配置区中，为目标选择一个分类。绑定后：
- AI 分类新数据时会优先判断是否与该目标相关，匹配则直接使用该分类
- 时间追踪依赖分类绑定，绑定后才能自动计算投入时间
- 若绑定的分类被禁用，该目标不再参与分类流程

### 右侧：计划书编辑

计划书列表显示当前目标下的所有计划书。点击切换文档，右侧编辑器加载对应内容。

操作按钮：保存、刷新、新建，以及包含重命名、复制、归档、删除等功能的操作菜单。

**新建计划书：** 点击 `+` 按钮，输入名称后创建。编辑器内容在手动保存、切换计划书或切换选项卡时均会自动保存。

## ② 计划 — 任务（核心）

### todoblock 任务块

在计划书编辑器中，可以使用任务块（todoblock）来定义待办清单。在任务块中添加的内容，每行是一个待办项，支持缩进表示层级关系。只有任务块内的待办项才会被同步到任务池。

```
- [ ] 待办项
  - [x] 已完成子项
  - [ ] 子项
```

### 同步到任务池

计划书中的任务不会自动进入任务池。**需要手动触发同步：**

1. 在左侧选择要同步的计划书
2. 点击右侧"同步"按钮
3. 系统先保存当前编辑内容，然后检查需要同步的任务变更
4. 若检测到待删除任务，弹出确认框——选择"确认删除"或"保留全部"
5. 同步完成后任务出现在任务池中

### 冲突处理

当编辑器内容与本地文档不一致时（例如在任务池操作了任务但编辑器未保存），点击刷新按钮会弹出冲突对话框：

| 选项 | 说明 |
|------|------|
| **使用当前窗口所编辑的内容** | 当前窗口内容覆盖文档，以窗口编辑为准 |
| **使用本地文档的内容** | 丢弃窗口未保存内容，重新加载文档 |

### 任务池操作

| 操作 | 说明 |
|------|------|
| 状态筛选 | 待处理 / 已安排 / 已完成 / 全部 |
| 目标/计划书筛选 | 按关联的目标或计划书过滤 |
| 勾选完成 | 自动回写计划书 |
| 删除 | 有确认弹窗 |

## ③ 任务 — 日历

**从任务池拖拽任务到日历**中的日期格子，即可将任务安排到具体日期。状态从"待处理"变为"已安排"，子任务会跟随父任务一起分配。

**从日历拖回任务池**可将任务恢复为待分配状态。

日历显示已选日期范围内的每一天及其任务数量。点击左侧日历的日期可联动右侧每日任务视图。

---

## ④ 日历 — 每日

**每日任务**展示指定日期的所有任务：

| 功能 | 说明 |
|------|------|
| 日期选择 | 通过左侧日历联动 |
| 任务输入框 | 输入内容按 Enter 添加，可关联目标和计划书 |
| 视图切换 | "显示全部未完成"：同时展示当天 + 所有未完成任务 |
| 展开子任务 | 查看子任务列表 |
| 任务卡片 | 勾选完成、修改内容、设置颜色、记录拖延原因 |

**任务来源：**
- 从任务池拖拽分配到该日期的
- 在当前界面直接添加的
- 来源于计划书同步并已安排的
