## 1. 时间线页面包含什么？

时间线按时间顺序展示当日活动记录。页面布局分为**两个层级**：

#### 主体布局（始终可见）

```
┌──────────┬────────────────────────┬──────────────┐
│ 左侧标签区 │    中间时间线主区域       │ AI 分析列    │
│ (自定义备注)│  (时间轴 + 时间块网格)    │ (行为摘要)   │
└──────────┴────────────────────────┴──────────────┘
                          ↕ 点击时间块触发
                    ┌──────────────────────┐
                    │  Event Details 面板   │ ← 浮动/覆盖在右侧
                    │  (活动详情 + 编辑)     │
                    └──────────────────────┘
```

| 区域 | 功能 | 层级 |
|------|------|------|
| **左侧标签区** | 自定义备注的存放位置 | 主体 |
| **中间时间线主区域** | 时间轴 + 活动记录（缩略图/详细视图） | 主体 |
| **AI 分析列** | 时间线固有的右侧列，展示各时间段 AI 行为摘要 | 主体 |
| **Event Details 面板** | 点击时间块后浮出的右侧详情面板，展示选中活动的详细数据和编辑功能 | 弹出层 |

## 2. 顶部工具栏

| 控件 | 功能 | 操作方式 |
|------|------|---------|
| **日期导航** | 切换日期 | 左右箭头 / 点击打开日历 |
| **缩放** | 缩放时间轴的显示粒度 | 显示比例 + 重置按钮 / Ctrl+滚轮 |
| **过滤** | 按时长过滤活动记录 | 输入分钟数，只显示大于该时长的记录 |
| **缩略图开关** | 切换缩略图/详细视图 | 开关切换 |

**缩略图配置（ThumbnailConfig）：**
- `hourGranularity`：时间粒度（1h/2h/3h/4h/6h）
- `categoryLevel`：分类级别（main / sub）
- `maxCategories`：最多显示分类数（Top N）

---

## 3. 缩略图模式

- 按时间段展示分类占比的色块
- **点击色块中的某个分类** → 弹出 **Event Details 面板**，显示该时段的统计数据（旭日图 + 柱状图）

---

## 4. 详细视图模式

### 时间块活动记录
- 每个时间块显示：应用名、活动时长
- **点击时间块** → 弹出 **Event Details 面板**，显示该活动的详细数据

### Event Details 面板（活动详情/编辑）

这是点击时间块后在最右侧浮出的独立面板，有三种触发形态：

| 触发方式 | 面板内容 |
|---------|---------|
| **详细视图点击活动时间块** | 显示该条活动日志的完整数据：事件标题、时间范围、持续时间、当前分类（主分类+子分类）。支持直接在面板上修改分类 |
| **缩略图视图点击分类色块** | 显示该时间段的旭日图 + 柱状图统计 |
| **点击 AI 分析列的摘要** | 显示该 AI 分析的完整详情（同下方第 6 节） |

**在 Event Details 面板修改分类：**

面板显示当前活动日志的详细数据，包含分类下拉菜单。选择新的主分类和子分类后自动保存。

**注意：** 此处修改只影响当前单条记录。如果同一应用后续仍会分错，建议去 [分类管理 → Map Cache](03-分类管理.md) 修改。

## 5. 自定义备注 (CustomBlock)

### 添加
- 鼠标移动到时间线**左侧空白标签区** → 出现 `+` 号按钮 → 点击打开编辑弹窗
- 编辑弹窗可填写文本、设置时间范围、颜色

### 编辑/删除
- 点击已创建的备注色块或左侧标签 → 打开编辑弹窗
- 弹窗可编辑内容、时间、颜色，并可绑定待办事项和分类
- 支持删除操作

**自定义备注与待办事项关系：** 可在编辑弹窗中绑定待办事项，绑定后在备注上显示待办内容。

## 6. AI 行为分析列与详情 (BehaviorAnalysis)

### 分析列（主体布局固有部分）
- 位于时间线网格的右侧，始终可见（除非被折叠）
- 为每组相关的时间块显示一条 AI 生成的行为摘要（如"讨论单聊API设计"）
- 用于快速浏览和理解时间线的整体脉络

### 行为分析详情（点击分析摘要弹出）

点击分析列的某条摘要，弹出 **Event Details 面板**（行为分析模式），显示完整内容：

| 数据项 | 后端字段 | 说明 |
|--------|---------|------|
| 标题 | `title` | AI 对该时间段的任务总结 |
| 时间/时长 | `start_time`, `end_time` | 活动起止时间和总时长 |
| 截图数 | `screen_count` | 该段时间内的截屏数量 |
| 总结 | `behavior_summary` | AI 的自然语言概括 |
| 详细行为 | `behavior[].behavior_items` | 按时间顺序列出的具体操作，每条有时间戳 |

### AI 分析前置条件
- 设置中已开启截图监控
- 当前 AI 模型必须支持多模态（能理解图片）

## 常见操作

### 如何查看某天的详细活动？

左侧导航 → Timeline → 日期导航选择目标日期 → 关闭缩略图开关查看详细记录

### 如何查看某条活动日志的完整数据？

在详细视图中点击该时间块 → 右侧弹出 Event Details 面板 → 显示活动标题、时间、分类等

### 如何添加一条自定义备注？

悬停左侧空白时间标签区 → 点击 `+` 号 → 填写内容、时间、颜色 → 保存

### AI 分析不显示怎么办？

1. 确认已配置 AI 服务商和模型（截图分析还需多模态模型）
2. 点击首页的 Refresh 触发 AI 分析
