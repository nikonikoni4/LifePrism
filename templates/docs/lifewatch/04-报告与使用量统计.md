# 第一部分：报告 (Reports)

## 1. 报告页面包含什么？

报告页面提供多维度的时间使用分析，按月/周/日查看。

| 模块 | 功能 |
|------|------|
| **时间维度 Tab** | 切换 每日总结 / 每周总结 / 每月总结 |
| **日期导航** | 上月/本月/下月 按钮切换报告周期 |
| **重新计算按钮** | 数据更新后手动刷新报告 |
| **月度时间分布趋势** | 各分类的折线图（可点击数据点查看当日详情，图例可筛选显示/隐藏分类） |
| **月度活跃热力图** | 日历格式热力图，颜色深浅表示活跃度（可按分类筛选） |
| **月度 Todo 追踪** | 当月待办任务完成率指标 |

### 交互汇总

| 交互 | 效果 |
|------|------|
| 切换每日/每周/每月 Tab | 切换报告维度 |
| 点击上月/本月/下月 | 切换报告期 |
| 点击重新计算 | 重新生成报告数据 |
| 悬停/点击趋势图数据点 | 查看/查看当日详情 |
| 点击图例 | 显示/隐藏对应分类 |
| 点击热力图日期 | 查看该日活跃详情 |

# 第二部分：使用量统计 (Usage)

## 1. Usage 页面包含什么？

展示 AI 服务的 Token 消耗量和成本统计（所有成本为基于输入输出 Token 的估算值）。

| 模块 | 数据项 | 说明 |
|------|--------|------|
| **Token Usage** | 今日/累计 Token、Input/Output 单价、总费用、Token 分布环形图 | Token 消耗概览 |
| **Data Processing** | Records Processed（处理记录数）、Today Tokens/Cost、Avg Tokens/Cost | AI 分类消耗详情 |
| **Other Usage** | Total Tokens、Total Cost | 非分类 API 调用（如 AI 对话）消耗 |
| **7-Day Usage Trend** | 柱状图展示过去 7 天消耗趋势 | 可切换 Token/成本视图 |

### 操作

| 操作 | 方法 |
|------|------|
| 切换日期 | 顶部日期选择器选择日期 |
| 修改 Token 单价 | 在 **Settings** 中配置 AI 服务商时设置 Input/Output Token 单价 |
| 切换 7天趋势图 | 在 Token 数量和 Cost 成本视图之间切换 |

## 常见操作

### 如何查看月度报告？

左侧导航 → Reports → 选择每月总结 Tab → 上月/下月/本月 切换月份

### 报告数据未更新怎么办？

点击 **重新计算** 按钮手动刷新。

### 如何查看 Token 消耗？

左侧导航 → Usage → 查看 Token Usage（今日/累计）和 Data Processing（分类消耗）

### 费用估算不准确？

在 **Settings → AI 服务配置** 中设置正确的 Input/Output Token 单价。
