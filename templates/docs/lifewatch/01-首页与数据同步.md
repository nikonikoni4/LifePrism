## 1. 首页包含哪些模块？

首页展示当日活动概览，包含以下 5 个模块：

| 模块 | 后端字段 | 组件名 | 功能简述 |
|------|---------|--------|---------|
| **Activity Summary** | `activity_summary` | ActivitySummaryHeader | 日期导航 + 柱形趋势图 + 同步操作按钮 |
| **Today's Focus** | `todolist` | TodoListWidget | 今日待办事项列表，可勾选完成 |
| **Time Overview** | `time_overview` | TimeOverviewWidget | 当日时间分配的旭日图 |
| **Top Applications** | `top_app` | ActivityDetailsWidget | 当日使用时长最长的应用排行 |
| **Top Titles** | `top_title` | ActivityDetailsWidget | 当日出现频率最高的窗口标题排行 |

## 2. Activity Summary（活动趋势图）

#### 柱形图
- 展示过去约 30 天的活动时长趋势
- **点击柱形**可切换到该日期的详情

#### 日期导航
- 通过 `<` `>` 箭头按钮逐日切换
- 点击日期文本打开日历选择器跳转到任意日期

#### 按钮

| 按钮 | 代码名称 | API 端点 | 功能 |
|------|---------|---------|------|
| **Refresh** | Refresh 按钮 | `POST /api/v2/sync/activitywatch` (SyncAPI.incrementalSync) | **增量同步**：从数据库最新记录时间同步到现在。速度快，不覆盖已有数据 |
| **Sync Data** | Sync Data 按钮 | `POST /api/v2/sync/activitywatch/timerange` (SyncAPI.syncByTimeRange) | **时间范围同步**：弹出对话框，用户选择起止日期后同步该范围内的数据。会覆盖选定范围内的已存在数据 |

#### Refresh 按钮的行为

点击后执行 `SyncAPI.incrementalSync()`，触发两件事：
1. **电脑日志分类**：对新获取的未分类活动数据进行 AI 分类
2. **截图分析**：仅在设置中开启截图监控 + 当前模型支持多模态时触发

#### Sync Data 按钮的行为

点击后弹出同步对话框，用户选择**开始日期**和**结束日期**，确认后执行 `SyncAPI.syncByTimeRange()`。用于首次使用或恢复误删数据。

#### 分类筛选

- **CategoryFilter** 下拉菜单：按分类筛选柱状图中的数据
- 可选只显示特定分类的时间趋势

#### 自动增量同步

> **实现位置**：后端 `schedule_service.py`，Cron 表达式 `0 10 * * *`

系统每天早上 **10:00 自动执行一次增量同步**（等同于点击 Refresh）。如果用户超过 10:00 未打开软件，下次打开时自动**补做一次同步**，确保数据不遗漏。

**判断逻辑：**
1. 系统启动时检查当前时间是否超过 10:00
2. 如果是，检查 `.schedule_state.json` 中今天是否已执行过该任务
3. 如果今天未执行 → 异步执行一次增量同步
4. 如果今天已执行过 → 跳过

## 5. Top Applications & Top Titles

- **Top Applications**：展示当日使用时长最长的应用列表（按时长降序）
- **Top Titles**：展示当日出现频率最高的窗口标题列表
- 两者均为数据展示，无交互操作

## 6. 数据来源

电脑行为日志的数据来源有两种，通过设置中的 `monitor_type` 控制：

| 来源 | 配置值 | 说明 | 配置位置 |
|------|--------|------|---------|
| **ActivityWatch** | `activitywatch` | 外部开源工具，需从 GitHub 下载安装（搜索 ActivityWatch）。数据路径通过 `aw_db_path` 设置 | Settings → 存储与数据源 |
| **内置监控** | `lifeprism` | 软件内置的 Windows 监控功能，默认开启。无需额外安装 | Settings → 存储与数据源 |

**默认值：** `lifeprism`（内置监控）。

**数据清洗流程：** `data_clean.py` 根据 `settings.monitor_type` 选择对应的 provider 获取原始事件数据，然后进行统一的时间戳标准化、短活动过滤和缓存匹配。两种来源的后续处理流程一致。

## 常见操作

### 怎么同步数据？

| 场景 | 操作 |
|------|------|
| 日常打开应用后更新数据 | 点击 **Refresh**（增量同步） |
| 首次使用或数据恢复 | 点击 **Sync Data** → 选择日期范围 → 确认同步 |
| 数据被误删 | Sync Data 选择被删除的日期范围重新同步 |

### 怎么查看某天的数据？

- 点击柱形图中对应日期的柱形
- 或用 `<` `>` 箭头逐日切换
- 或点击日期文本打开日历选择器
