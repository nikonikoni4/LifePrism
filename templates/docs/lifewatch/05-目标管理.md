# 目标管理（Goals）

> Goals 页面是"目标 → 计划 → 任务 → 日程 → 执行"的完整工作流枢纽。支持**双栏**（组合视图）和**单栏**（独立视图）两种布局。

## 页面布局

| 模式 | 选项卡 | 说明 |
|------|--------|------|
| **双栏（默认）** | 目标 — 计划 / 计划 — 任务 / 任务 — 日历 / 日历 — 每日 | 左右面板联动，共 4 个组合标签 |
| **单栏** | 目标 / 计划书 / 任务池 / 任务分配 / 每日任务 | 每次只显示一个独立视图，共 5 个标签 |

- **切换布局**：顶部导航栏右侧的 `Maximize`（单栏）/ `Columns`（双栏）按钮
- **切换标签**：点击胶囊选项卡，或使用左右箭头按钮循环切换
- 双栏中 `ActiveTab` 映射：`goals`→目标-计划、`plans`→计划-任务、`pool/assign`→任务-日历、`daily`→日历-每日

## ① 目标 — 计划

**双栏左侧：GoalListView（目标列表）**

| 功能 | 操作 | 说明 |
|------|------|------|
| **统计卡片** | 自动显示 | 进行中/已完成数量、总投入小时、里程碑完成数 |
| **新建目标** | 点击 `+ Add New Goal` 按钮 | 弹出创建弹窗，输入名称、简介，可选配主题色、分类、日期范围 |
| **查看详情** | 点击目标卡片 | 展开全屏详情面板（GoalDetailView） |
| **删除目标** | 悬停卡片 → 点击垃圾桶图标 | 弹出确认弹窗，确认后级联删除关联计划书和任务 |
| **标记完成/进行中** | 悬停卡片 → 点击对勾按钮 | 切换 `active` / `completed` 状态 |
| **刷新投入时间** | 点击卡片上的刷新图标 | 调用 `POST /api/v2/goal/goals/{id}/refresh-time` 从行为日志重新计算 |

**统计卡片字段：**
- `activeGoals.length` — 进行中目标数
- `completedGoals.length` — 已完成目标数
- `goals.reduce((sum, g) => sum + parseInt(g.timeInvested), 0)` — 总投入小时
- `milestones.filter(m => m.state === 1).length` — 已完成里程碑数

### 目标详情面板（GoalDetailView）

展开后覆盖全屏，背景色随卡片主题变化。

| 区域 | 交互 |
|------|------|
| **标题** | 内联编辑，点击直接修改 |
| **目标简介** | 多行文本框，placeholder: "添加目标简介..." |
| **已进行天数** | 自动计算 `startDate` 至今 |
| **已投入时间** | 自动跟踪 或 手动记录 |
| **价值意义** | 文本输入，记录目标对你的意义 |
| **每日承诺** | 文本输入，记录每天推进目标的具体行动 |
| **配置区（可折叠）** | 主题色选择（6 色）、**分类绑定**、开始/目标日期、时间跟踪模式切换 |
| **里程碑** | 水平轴线展示，点击圆点切换完成状态，点击编辑按钮增删改排序 |
| **日志** | 添加日志条目，可选心情标签（`joy`/`calm`/`frustrated`/`neutral`） |

所有修改需点击底部 **保存更改** 按钮提交，调用 `PATCH /api/v2/goal/goals/{id}`。

### 分类绑定功能

在目标详情→配置区，通过 CategoryFilter 组件选择主分类和子分类。

**影响：** 当目标绑定了某个分类后，AI 分类新数据时**优先判断**是否与此目标相关。如果匹配，直接使用目标绑定的分类，跳过常规 AI 分类流程。同时，时间追踪依赖分类绑定——只有绑定了分类，`refreshTimeInvested` 才能正确计算该目标累计投入时间。

> **禁分类联动：** 如果目标绑定的分类被**禁用**，该目标不再纳入分类流程。

**双栏右侧：PlanDocListView（计划文档）**

**顶部工具栏：**
- `TARGET` 下拉选择器：切换目标（`selectedGoalId`）
- `PLAN DOC` 下拉选择器：选择当前目标下的计划书
- `Save` 保存按钮：手动保存当前编辑器内容（调用 `PATCH /api/v2/goal/plan-docs/{id}`）
- `Refresh` 刷新按钮：从后端重新加载文档内容
- `+` 新建按钮：创建新计划书，默认名称 `{目标名称}-planDoc-{随机6字符}`
- `···` 更多操作：Duplicate、Rename、Archive、Delete（删除有确认弹窗）

**编辑器：**
- 使用 PlanDocEditorView（Markdown 编辑器）
- 支持标准 Markdown 语法
- **任务块语法 `todoblock`：**
  ```
  <!-- lp:todoblock -->
  - [ ] 任务 1
  - [ ] 任务 2
    - [ ] 子任务 2.1
  <!-- /lp:todoblock -->
  ```
  只有 `todoblock` 标签内的 `- [ ]` 项才会被同步到任务池。

**保存机制：**
| 场景 | 行为 |
|------|------|
| 手动点击 Save | 调用 API 保存，更新 store |
| 切换计划书 | 自动保存当前文档（无 Toast） |
| 切换标签页 | 自动保存（组件卸载时） |
| 点击同步按钮 | 先自动保存编辑器内容，再执行同步 |

## ② 计划 — 任务

**双栏左侧：PlanDocListView（同上）**

**双栏右侧：TaskPoolView（任务池）**

| 功能 | 说明 |
|------|------|
| **同步按钮** | 将计划书中的 `todoblock` 任务解析到任务池。调用 `POST /api/v2/taskpool/sync` |
| **目标筛选** | 按目标过滤任务池 |
| **计划书筛选** | 按计划书过滤 |
| **状态筛选** | 待处理(`pool`) / 已安排(`scheduled`) / 已完成(`completed`) / 全部(`all`) |
| **清空筛选** | 重置目标和计划书筛选条件 |
| **任务操作** | 勾选完成、修改内容、删除（有确认弹窗） |

**同步流程（三段式）：**
1. **触发同步** → 先保存编辑器内容
2. **dry_run 预检** → API 返回待删除任务的预览 (`to_delete` 列表)
3. **确认** → 用户选择"确认删除"或者"保留全部" → 执行最终同步

API 参数：
- `dry_run: true` — 仅返回变更预览，不写数据库
- `confirm_delete: true` — 确认删除计划书中已移除的任务
- `confirm_delete: false` — 保留计划书中已移除的任务（不移除任务池中的对应项）

**任务状态颜色标识：** `pool`=靛蓝、`scheduled`=紫色、`completed`=翠绿。已安排任务半透明显示带紫色边框。

## ③ 任务 — 日历

**双栏左侧：TaskPoolView（任务池）** — 禁用内部拖拽排序

**双栏右侧：CalendarView（日历网格）**

**核心操作：拖拽分配**
- 从左侧任务池**拖拽**任务到右侧日历的**日期格子**中
- 拖入后任务状态自动从 `pool` → `scheduled`，并写入 `scheduledDate`
- 子任务随父任务一起分配（递归获取所有子任务 ID）
- 支持反向拖拽：从日历拖回任务池 → 状态恢复为 `pool`
- 跨区域拖拽由 `CrossAreaDndProvider` 管理，`activationDistance=5`

**日历导航：**
- 左右箭头切换日期范围（默认：今天-4 ~ 今天+3）
- 点击右侧"选择日期"按钮打开 `GlassCalendar` 弹窗（支持范围选择，显示 2 个月）
- 显示选定范围内的天数统计

## ④ 日历 — 每日

**双栏左侧：CalendarView（日历网格）** — 同上，作为日期选择器

**双栏右侧：DailyTaskView（每日任务）**

| 功能 | 说明 |
|------|------|
| **日期选择** | 通过左侧日历联动 `selectedDate` |
| **状态栏** | 显示总任务数、已完成数、逾期数 |
| **视图模式** | `daily`（仅当天 scheduled/completed） / `all_uncompleted`（当天 + 所有未完成任务） |
| **快速添加** | 顶部 TaskInputBox 输入内容即创建，可选关联目标和计划书 |
| **子任务** | 点击任务卡片的 `+` 按钮添加子任务，弹窗中可选颜色、开始日期、预期完成日期 |
| **任务卡片** | 勾选完成、修改内容、设置颜色、展开详情设置日期和拖延原因 |

**每日任务的数据源：**
- 左侧日历选中的日期 → 过滤 `tasks.scheduledDate === dateStr` 的任务
- 直接从 DailyTaskView 输入框添加的任务
- 从任务池拖拽分配到该日期的任务

**拖延原因记录：** 展开任务卡片可设置 `delayReason`，用于复盘分析。

## 文件保存与同步方向

```
┌──────────────┐    手动同步（点击同步按钮）    ┌──────────────┐
│  计划书 MD   │ ──────────────────────────→  │  任务池/每日  │
│  (Markdown)  │ ←── 自动回写（完成任务时）──  │  (SQLite)    │
└──────────────┘                               └──────────────┘
```

| 方向 | 触发方式 | 行为 |
|------|----------|------|
| 计划书 → 任务池 | 手动点击"同步"按钮 | 解析 todoblock，创建/更新/删除任务 |
| 任务池 → 计划书（回写） | 自动 | 完成任务时自动将 `[ ]` 改为 `[x]` 写回 MD 文件 |
| 计划书保存 | 手动 / 自动 | 手动点保存 / 切换文档/标签时自动保存 |

**各视图权限：**
| 视图 | 可操作 |
|------|--------|
| 计划书视图 | 通过编辑 MD 文件增删改查任务 |
| 任务池视图 | 删改查、同步，**不可新增**（任务来源 = 计划书同步或每日视图） |
| 任务分配视图（日历） | 仅可修改日期（拖拽分配）和查看 |
| 每日任务视图 | 增删改查（无计划书关联的任务不出现在计划书中） |
